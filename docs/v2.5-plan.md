## Theme Spine

### Primary — W-1 resizable three-pane workspace

通常の作業面を **Workspace / Editor / Preview・Reference** の三領域として扱う。

Acceptance:

1. 左 Workspace と中央 Editor の区切りをドラッグまたは左右キーで変更できる。
2. 中央 Editor と右ペインの既存区切りも、通常 Preview と Reference でそれぞれ保存・復元する。
3. 左幅は 200–400 px、右幅は 25–75% に制限し、960 px の最小ウィンドウでも中央領域を消さない。
4. Workspace 折りたたみ、L Mode、Reading Focus では不要な区切りを表示しない。
5. 保存先は app-private local storage。Markdown、workspace、OKF を書き換えない。

## Operating Rules

1. **1 run = 1 verifiable slice.** 失敗テストまたは acceptance を先に固定できるものから。
2. **Published `2.4.0` is hotfix-only** until a later store line is intentionally opened.
3. Package surfaces are **`2.5.0`** for the active development line; build
   counter changes and store upload remain separate human-gated work.
4. Hard rails: `docs/security-boundary.md` + `docs/assist-surface-strategy.md` + Surfaces 表。
5. App Store レーンは Agent Workbench / 外部 CLI agent を載せない。Local Assist は現状のオンデバイス境界を変えない。

## TestFlight-ready gate

- Frontend / Rust / App Store surface の必須 gate が green。
- 2.5.0 の App Store lane app が build でき、三ペイン幅と R-1 を実アプリで smoke。
- signed universal app / installer pkg の署名、entitlements、metadata、checksum を確認。
- candidate provenance が clean source commit を指す。
- **upload は人間承認**。pkg 完成だけで TestFlight 配信済みとは書かない。
