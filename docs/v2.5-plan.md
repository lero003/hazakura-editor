# v2.5 Plan — Local Assist Depth + Quiet Reading Polish

Status: Active planning (v2.4 shipped)
Scope: Next product line after published `2.4.0`
Authority: Medium
Last reviewed: 2026-08-07

## Purpose

`2.4.0` で Book depth（OKF v0.2・章 Diff など）を閉じた。  
**v2.5** は主コピーの第 3 句 — **ローカル AI で整える** — を一段進め、
Safe Editor の境界は広げない。

この文書は **v2.5 プラン正本** である。実装キューの正本は
`docs/current-work.md`。会話 UX の設計詳細は
`docs/local-assist-conversational-edit-ux.md`。

## Context After 2.4

| Fact | Value |
|------|--------|
| Published Mac App Store | **`2.4.0`** (user-reported shipped; treat as closed store line) |
| Source / package baseline | **`2.4.0`** line immutable once tagged; do not rewrite tags |
| Active product phase | **v2.5** — Local Assist conversational edit + adjacent polish |
| Deferred | 縦書き; Compare Center; static lint; anydoc adoption |

v2.0–v2.4 で閉じた本の基盤は維持する。v2.5 は Book を広げず、
**Assist 面と小さな読み polish** を優先する。

## v2.5 Product Intent

一行:

> 対象文章を固定し、オンデバイス AI と変更案を会話し、納得した案だけを
> 明示反映する。読む面の小さな摩擦も静かに直す。

北星との対応:

| 句 | v2.5 での扱い |
|----|----------------|
| Markdown で書く | 変えない（source 正本） |
| 本として読む | 参照テキストのフォントなど **小 polish のみ**。縦書きは park |
| ローカル AI で整える | **主レーン** — 会話型 Local Assist |

## Theme Spine

### Primary — Local Assist conversational edit

設計 SoT: `docs/local-assist-conversational-edit-ux.md`

| ID | Slice | Notes |
|----|--------|--------|
| **A-1** | **P1 生成と本文反映の分離** | 変更案はウィンドウ内のみ。本文不変。最初にこれを単独で |
| **A-2** | **P2 対象固定 + 複数ターン** | 固定対象、追加指示、案基準の再生成 |
| **A-3** | **P3 明示「文書へ反映」** | stale 拒否、AiEditTransaction、Review Bar |
| **A-4** | **P4 UI / i18n / a11y 仕上げ** | 会話欄・composer・empty/stale |

Operating rule: **1 run = 1 ID（または ID 内の更に小さい検証可能単位）**。  
A-1 完了前に A-2 以降を同時に広げない。

### Secondary — Reading / reference polish

| ID | Slice | Notes |
|----|--------|--------|
| **R-1** | **テキスト参照に previewFontSize を効かせる** | `.reference-text-surface` の 12.5px 固定をやめ、`--preview-font-size` と揃える。PDF/画像は対象外。専用設定 UI は増やさない |

R-1 は A スライスの合間の **小 polish** として昇格してよい。
Book の B-2 display TOC 等は **v2.5 主キューに載せない**（摩擦が出たら residual）。

### Later in v2.x / v3 — Core AI writing models (whitelist)

足りない能力への回答として、**文章系特化の on-device モデル**を
**ホワイトリスト形式で DL / 管理 / 利用**する道を開く（製品意図）。

| ID | Slice | Notes |
|----|--------|--------|
| **C-0** | **Core AI 方針スパイク（設計のみ）** | 配布レーン、サイズ、可用性、同意、削除、App Store 説明 |
| **C-1** | **Allowlist catalog + download / verify / delete** | 任意 URL 禁止。署名または固定 digest。network はモデル取得に限定し、推論はオンデバイス |
| **C-2** | **Local Assist から allowlisted model を選択利用** | Foundation Models が主、Core AI は任意。fallback でクラウド推論しない |

C-* は A-1〜A-3 の体験が固まってから。**会話 UX と同時に実装しない。**  
詳細境界は `docs/assist-surface-strategy.md` § Core AI を正本にする。

### Evaluation only — anydoc

| ID | Slice | Notes |
|----|--------|--------|
| **I-0** | **anydoc 調査メモ** | Office→Markdown 変換の品質・サイズ・Import 導線適合。採用未決。docx 限定スパイクまでが上限。PDF は既存 Import Assist 優先 |

**v2.5 に anydoc を製品採用しない。** 需要が再現したら v2.6+ で再判定。

## Explicitly out of v2.5

- Static writing lint / click-apply engine
- Recipe auto-load / workspace manifest as truth

- Moving published tags

## Operating Rules

1. **1 run = 1 verifiable slice.** 失敗テストまたは acceptance を先に固定できるものから。
2. **Published `2.4.0` is hotfix-only** until a later store line is intentionally opened.
3. Package bump to **`2.5.0`** は実装レーンを開くときの明示ステップ（docs 先行可）。
4. Hard rails: `docs/security-boundary.md` + `docs/assist-surface-strategy.md` + Surfaces 表。
5. App Store レーンは Agent Workbench / 外部 CLI agent を載せない。Local Assist はオンデバイスのみ。
