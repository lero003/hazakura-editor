# Hazakura Editor 2.7.0 Source / Local App Candidate

Status: Local candidate; GitHub source tag and Release pending explicit approval
Scope: M-0a OS-27前の安全な境界整備
Authority: Medium
Last reviewed: 2026-08-29

`2.7.0` is a local development and App Store/TestFlight candidate. The owner
plans to send it to App Review, but upload, processing, approval, publication,
and a GitHub source tag are not yet recorded here. The published Mac App Store
line remains `2.6.2` (user-confirmed 2026-08-28; staged rollout).

## What changed

- Local Assist keeps one immutable process-local `SystemLanguageModel.default`
  in the helper and creates a fresh `LanguageModelSession` for each request.
- Rust owns the internal backend wire and currently injects only
  `backend: "system_default"`; missing remains compatible with older Rust.
- Swift rejects `coreai`, `mlx`, and unknown backend values before model
  invocation. Public TypeScript / Tauri requests cannot select a backend.
- Existing Conversation / Proposal / Diff / explicit Apply, no auto-save, no
  cloud fallback, no tool calling, and Safe Editor boundaries remain intact.

## Explicitly not included

This candidate adds no MLX package or runtime, model import/download/storage,
model ID/revision/path/URL field, remote code or shell/Python execution,
settings UI, provider marketplace, or App Store feature exposure. M-0b stays
stopped until C-2 and an Xcode 27 / macOS 27 build lane exist.

## Local verification

The focused helper, Rust, TypeScript, and App Store surface gates passed in the
M-0a cycle. The owner reports the existing Local Assist flow as broadly okay.
A local `2.7.0` / build `123` package exists. Its metadata and SHA-256 are
recorded in ignored `docs/internal/app-store-candidates/latest.json`.

The package was produced while the v2.7 version/docs/config transition was
still uncommitted, so the internal note records `sourceDirty: true`. The v2.7
freeze commit is a reproduction boundary for that tree, not proof that the
package was built from an already-clean commit.

## Build boundary

```bash
npm run release:candidate -- --with-app-store-pkg --no-prune-pkgs
```

The command requires the local Apple Distribution and 3rd Party Mac Developer
Installer identities. It creates a signed local `.pkg`; it does not upload to
App Store Connect. A source tag or GitHub Release requires a separate explicit
decision.

## Known limits

- No Xcode 27 / macOS 27 `MLXLanguageModel` compile or runtime proof.
- Full physical Assist UI, IME, dirty-close, save-conflict, TestFlight
  processing, and App Store publication remain separate gates.
- Local `spctl` assessment may report Insufficient Context for this host;
  that is not publication proof.
