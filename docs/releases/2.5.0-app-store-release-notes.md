# Hazakura Editor 2.5.0 App Store Notes

Status: Local signed submission candidate prepared; no upload, review, or publication
Scope: v2.5 Safe Editor lane
Authority: Medium
Last reviewed: 2026-08-09

## Japanese

Hazakura Editor 2.5では、ワークスペース、編集領域、プレビュー／参照の幅を、
原稿や作業に合わせて調整できるようになりました。ドラッグとキーボードに対応し、
通常のサイドペインと参照ペインの幅はそれぞれこのMacのアプリ内に保存します。
Markdownやプロジェクトフォルダには書き込みません。

テキストの参照表示は、既存のプレビュー文字サイズ設定に合わせて読みやすくなりました。
大きなフォルダで表示上限を超えた場合は、非表示になった件数を明示します。

PDF、HTML、EPUBの書き出しでは、準備中の状態と完了先を示し、完了したファイルを
Finderに表示します。Bookの章立ては引き続きこのMacのアプリ内に保存され、
フォルダやOKFの順序を自動変更しません。

## English

Hazakura Editor 2.5 lets you resize the Workspace, editor, and Preview or
Reference areas to fit your manuscript and task. Separators support pointer and
keyboard control. Normal side-pane and Reference widths are remembered locally
in the app without changing Markdown or the project folder.

Text Reference now follows the existing Preview font-size setting. Large
folders also show the exact number of entries hidden by the bounded per-folder
display limit.

PDF, HTML, and EPUB export continue to show preparation and destination
feedback and reveal the completed file in Finder. Book chapter order remains
app-private and does not rewrite folder or OKF order.
