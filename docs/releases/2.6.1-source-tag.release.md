# Hazakura Editor 2.6.1 Source / Local App Candidate

Status: Local source and App Store package candidate; tag and publication pending
Scope: v2.6 Local Assist baseline plus theme / Preview reading and selection polish
Authority: Medium
Last reviewed: 2026-08-27

`2.6.1` is the next local candidate after the merged `2.6.0` A-1–A-4 source
work. It is not a source tag, TestFlight upload, App Review, GitHub Release,
or publication claim. Physical Assist validation remains a separate gate.

## What changed since 2.6.0

- Theme contrast and reading-surface polish: right Preview, e-book pages, and
  whole-book Reader keep opaque paper on joke themes; shell shaders, scanlines,
  boot, and ambient particles remain.
- Preview paint stability: image loads no longer rebuild the Markdown tree.
  Resolved images are cached and reapplied before paint.
- Long-document Preview selection: drag-to-edge auto-scroll, pause of
  editor↔Preview scroll sync during the pointer gesture, and no link follow
  when a click ends a text selection.

Local Assist conversation / Diff apply, save, and mutation boundaries are
unchanged from `2.6.0`.

## Release boundary

This is a local candidate. A generated App Store `.pkg` is a TestFlight-shaped
artifact only if signing succeeds on this host. It is not an upload or review
claim. Hazakura Local Assist remains an on-device preview companion with no
network fallback, auto-save, tool calling, or autonomous apply.

## Known limits

- Detached-window Assist physical smoke is still pending.
- Source tag, App Store Connect upload, App Review, and GitHub Release need a
  separate explicit approval.
- Published Mac App Store remains `2.4.0` (hotfix only).
