# Hazakura Editor 2.4.0 App Store Notes

Status: Candidate — signed local submission pkg prepared; no upload, review, or publication
Scope: v2.4 Safe Editor lane
Last reviewed: 2026-07-29

## Japanese

Hazakura Editor 2.4では、Bookの各章から現在の編集内容とディスク上の内容を
明示的に差分確認できるようになりました。未保存の編集はそのまま保ち、
確認だけでは保存や書き換えを行いません。

知識フォルダの点検とひな形はOKF v0.2に対応し、従来のv0.1フォルダも
引き続き読み取れます。新しいtrust・lifecycle・attestation項目はデータとして
安全に受け取るだけで、実行や自動評価は行いません。
「本っぽい章立て」のひな形では、はじまり・展開・転換・結末の4章と
全体構成・人物・設定のメモから、一冊の見取り図を確認できます。

Bookのツールバーも、よく使う操作が見つけやすいコンパクトな配置になりました。

## English

Hazakura Editor 2.4 adds explicit per-chapter review of the current editor
buffer against the chapter on disk. Reviewing does not save, apply, or rewrite
your Markdown.

Knowledge-folder review and starters now recognize OKF v0.2 while retaining
best-effort reading of v0.1 bundles. New trust, lifecycle, and attestation
fields are treated as data only; Hazakura does not execute or automatically
score them.
The book-like starter now shows a four-part chapter arc with overview,
character, and setting notes so the whole shape is visible from the start.

The Book toolbar is also more compact and keeps common actions easier to reach.
