## この版の位置づけ

`3.1.0`は開発中の次版。現時点では、Local Assistの表示整理と、英語表示・読み上げに
関わる言語境界、致命的エラーからの復旧面を改善している。Markdown / テキストsourceを
正本とし、生成結果をDiffで確認してから明示的に採用する契約は変えていない。

この文書は早期草案であり、署名済み候補、TestFlight提出、App Store申請、公開の証跡ではない。
Core AIのadapter・空catalog管理/選択は配布buildへ接続したが、本番モデル選定・
Apple-hosted asset配布、海外App Storeの設定、署名候補での英語受け入れは未完了。
完了していない機能は掲載文へ含めない。

## 掲載用（初期草案）

Local Assistの画面を見直し、対象範囲と依頼候補をすばやく確認できるようにしました。
生成中は同じボタンから停止でき、使用中のオンデバイスモデルも確認できます。
あわせて、英語表示時のエラー復旧と、本文・操作画面を読み上げるための言語情報を

## 現時点で実装済みの変更

### Local Assist

- 対象文書・選択範囲の要約を短くし、依頼候補をチップとして選べる構成へ整理した。
- 冗長な説明を減らし、依頼入力・モデル表示・送信操作を一つの入力面へまとめた。
- 送信ボタンを生成中は停止ボタンへ切り替え、停止処理中は重複操作を防ぐ。
- Local Assist窓でモデル選択枠を開き、入手済み・利用可能なモデルを切り替える契約を接続した。
  現在の本番catalogは空なので、Apple Intelligenceだけを確認・再選択できる。
- 設定にCore AIモデル管理面を追加した。Apple-hosted asset packが未公開の現在は
  「まだ公開されていません」と表示し、download / deleteを開始しない。
- 生成結果は従来どおり本体のDiffへ送り、採用前に確認する。自動保存・自動反映は行わない。

### 言語表示と復旧

- メイン窓とLocal Assist窓の表示言語をHTMLの言語情報へ反映し、初回描画前にも保存値を適用する。
- UIの言語を本文へ誤って継承させず、表やraw HTMLに明示された本文言語を保持する。
- 英語UIで致命的エラーが起きたときの復旧画面を英語化し、`null`や`false`が投げられた場合も
  復旧操作へ進めるようにした。

## TestFlight / 審査で確認すること（草案）

**最初に通す一本:** 文書を開く → Local Assistを開く → 依頼候補を選ぶ → 送信 →
生成中に停止 → 同じ窓から再依頼 → 完了した提案を本体Diffで確認 → 反映 → Undo。

- 停止要求後、片方の処理だけが先に完了しても操作ロックを維持し、両方の完了後に再依頼できる。
- 停止した古い生成結果が、次の依頼やDiffへ遅れて採用されない。
- モデル選択枠を開くとApple Intelligence 1件が選択済みで表示され、Escapeで閉じられる。
- 設定のモデル管理面はCore AI未公開を明示し、任意URL/pathの入力や無効なdownload操作を出さない。
- 日本語IMEの変換確定で依頼を誤送信せず、停止後に入力へ戻れる。
- VoiceOverで対象、依頼候補、入力、モデル選択、送信／停止、Diffへの移動を判別できる。
- 英語表示で致命的エラーの復旧面が英語になり、再読み込み操作へ到達できる。
- Local Assistの提案を破棄した場合と、採用後にUndoした場合のどちらもsourceを安全に戻せる。

## 提出用メモ（掲載本文に含めない）

- 現在の通常製品生成先はApple Intelligence（System）のみ。App Store buildはCore AI adapterと
  空catalogの管理/選択契約を含むが、Apple-hosted model packは未公開。テスト用Core AIモデルは
  Developer固定経路だけで、校正品質も不合格。本番catalogへ昇格しない。
- 外部AIへのnetwork fallback、background rewriting、auto-save、tool calling、
  workspace-wide indexingは追加していない。
- App Store laneにAgent Workbench、CLI Agent、任意コマンド実行、外部AI/API呼び出しを含めない。
- `src-tauri/tauri.conf.appstore.json`のbundleVersion変更は本作業と並行する既存変更であり、
  3.1.0署名候補や提出物の証跡として扱わない。候補作成時に別途記録する。
- `docs/international-launch/app-store-en-US.json`は3.0.3時点のproposal。3.1.0の最終metadataへ
  流用せず、実装・価格・地域・URL・スクリーンショットと照合して更新する。
