## What's New English

```text
This update refines Local Assist and on-device model settings.

- See your target document or selection, suggested requests, and current model more clearly.
- Stop generation from the send control, with duplicate actions blocked while checking availability or switching models.
- View model status, storage requirements, and recommended memory together on the on-device models page.
- Improved keyboard focus after model selection and clearer messages when a local model is missing.
- Improved the English error-recovery screen and language information used by assistive technologies for app controls and document content.

AI proposals still require your review and explicit approval. Nothing is applied or saved automatically. Local Assist availability depends on your environment and model readiness.
```

Hazakura Editor is a Markdown and plain-text editor for macOS. No app account or demo login is required. Writing, reading, and export can be tested without AI.

## Core AI追記を確定するための開発側メモ

- 現在のApp Store source catalogはGemma 4 E4B / Gemma 4 12B。Apple Intelligenceは別のSystem経路。
- Core AI helperはmacOS 27以降向け。アプリ本体の最低OSはmacOS 26.0。
- 設定の「オンデバイスモデル」へアプリメニューまたは設定内の入口から移動できる。
  Local Assist窓にもモデル選択枠がある。System選択は、そのMacでの利用可能を保証しない。
- Apple-hosted packのローカル`.aar`生成は完了。Apple processing / CDN / TestFlight取得・
  production load / 対象メモリでの品質は未受入。古い「`.aar`生成できない」という記録とは区別する。
- app-managed Custom Modelsは検出・検証・一覧・選択・helper接続まで実装済み。
  外部folder登録 / bookmark、フォルダを開く・作成・明示再スキャンするUIは未実装。
  審査担当者に手動のモデル配置を必須手順として要求しない。
- **提出直前に記入:** 実際に配布するモデル名、対応OS、必要空き容量・推奨メモリ、
  初回downloadから生成までの具体的手順、取得不可時の実表示、モデルのlicense / notice。
  未確定のまま貼る、配布済みと書く、見える未動作機能を説明から隠すことはしない。

## TestFlightで確認すること（開発側）

1. 初回起動と既存版更新で、文書の開く・保存・再起動・Preview・Reader・EPUB/PDF/HTML出力。
2. 日本語 / 英語でLocal Assistを開き、対象・依頼候補・モデル表示を確認。生成→停止→再依頼→Diff→明示反映→Undo→別操作で保存。
3. 設定とAssist窓の選択同期。availability確認中は送信不可。「使う」後は全テーマでfocus枠が見え、Tab / Shift+Tab / EscapeとVoiceOverで操作できる。
4. 出荷対象Apple-hostedモデルを初回取得し、進捗、取消、再開、検証、選択、生成、削除、再取得、再起動復元を確認。配信不能・容量不足・オフラインも確認。
5. localを出荷対象に含める場合は、実bundleでのload / 生成、破損・消失表示、System復帰、再ロード時のmemory / swapを確認。
6. 最小Assist窓、長いモデル名・文書名、日本語IMEの変換確定、英語メニュー・Help・復旧面を同一候補で確認。

これらは未完了の受入項目。テスト数や署名成功を代わりの証跡にしない。
