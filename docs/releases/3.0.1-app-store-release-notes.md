## この版の位置づけ

公開済み `3.0.0` に対する品質安定版。新しい機能は足さず、v3.0.0 のあとに外部レビューと
回帰テストで見つかった「操作の引っかかり」と「表示の不整合」だけを直した。
読み方・保存・書き出し・Local Assist の流れは `3.0.0` と同じで、境界も変えていない。

公開 build 番号と pkg のパス・SHA-256 は追跡ドキュメントへ固定せず、
`docs/internal/app-store-candidates/latest.json` を正本とする。このファイルには
提出・審査・公開の結果を書かない（結果が出たら追記する）。

## 掲載用（そのまま使う短縮版）

文字を入力するたびにmacOSのメニューバーがちらつく問題を修正しました。
選択中のタブが見える位置へ自動でスクロールし、同名のファイルは区別できるフォルダ名まで表示します。
ヘルプのサポート情報を表示言語に合わせ、日本語で読めるようにしました。

## このバージョンの変更（詳細文案）

書いているときの小さな引っかかりを直しました。

- **メニューバーのちらつき**: 本文を編集するたびに、macOS のメニューバーが一瞬描き直されて
  右側がちらつくことがありました。入力中はメニューを作り直さないようにし、保存など必要な
  状態が変わったときだけ切り替わるようにしました。
- **タブの見切れ**: タブを切り替えたとき、選択したタブが画面の外にあると見えないままに
  なっていました。見えていないときだけ、必要な分だけ横へ送って表示します。入力位置は
  エディタに残したままです。
- **同名ファイルの見分け**: 同じ名前のファイルを複数開くと、親フォルダ名まで同じ場合に
  区別できませんでした。区別できる最短のフォルダまでタブに表示します
  （例: `index.md — book-a/chapters`）。タブの読み上げ名と閉じるボタンの説明も同じ名前に揃えました。
- **サポート情報の表示**: ヘルプの診断画面に英語のままだった操作が残っていました。
  表示言語に合わせて日本語・かな・英語で表示し、コピーと再読み込みのまとまりにも名前を付けました。

Markdown source を正本とし、外部クラウドAIへの送信、auto-save、auto-apply、
background indexing を行わない境界は変わりません。

## TestFlight / 審査で確認すること

**最初に通す一本**: 保存済みの文書に最初の1文字を入力 → メニューバーの右側がちらつかない →
保存メニューが有効になる → ⌘S で保存して保存メニューが無効に戻る。

- メニューバー: 数十文字と Enter、日本語 IME の変換を続けてもメニューがちらつかないこと。
  未保存のタブと保存済みのタブを切り替えて、保存メニューの有効・無効が正しいこと。
- タブ: 長い名前のタブを10件以上開き、次／前のタブ移動・新規追加・タブを閉じたあと・
  ウィンドウ幅を狭めたときに、選択中のタブが見える位置にあること（入力位置はエディタに残ること）。
- 同名タブ: `book-a/chapters/index.md` と `book-b/chapters/index.md` のような構成で、
  タブと読み上げ名が区別できること。名前変更・別名保存のあとも崩れないこと。
- サポート情報: コピー、コピー結果、再読み込みの表示が表示言語に合うこと。
  コピー結果が画面読み上げで伝わるかは、VoiceOver で確認したい点。
- v3.0 から持ち越しの未受入: 日本語 IME、保存衝突、再起動後の復元、VoiceOver、
  Local Assist の生成 → 停止 → 反映 → Undo。

不具合報告には OS 版、アプリ版/build、再現操作、期待と実際を記載してください。
個人原稿は不要です。可能なら内容を置き換えた短い再現用原稿を添えてください。
