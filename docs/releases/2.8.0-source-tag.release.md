# Hazakura Editor 2.8.0 Release Candidate

Status: Release preparation; publication and physical validation pending
Scope: Detached Local Assist conversation and System helper integration
Authority: Medium
Last reviewed: 2026-09-07

## Changes

- Local Assist opens in a separate native window. A tall conversation log and
  bottom composer replace the sidebar; target details, help and presets start collapsed.
- Requests and app-known generation, completion and failure status share the
  conversation. Main-window Diff remains the authoritative review surface.
- Cancellation waits for generation to finish before another request starts.
  Recovery restores a proposal only for the same conversation, document,
  range and original text. Late or duplicate results cannot replace current work.
- The System model is reused within the helper process, with a fresh session
  per request. Rust owns the backend field; unsupported values fail closed.
- Explicit reviewed Apply, Undo and no auto-save remain unchanged. No MLX
  runtime, model download/selection, cloud fallback or tool calling is added.

and its existing package remain historical candidates, not v2.8 evidence.

## Verification — integrated candidate

- Clean locked npm install; full Vitest and App Store surface tests.
- TypeScript and Vite checks included in successful macOS app build.
- Rust: 369 passed, 2 ignored; formatting check passed.
- Swift helper fixture: JSON-over-stdio smoke passed; live helper build passed.
- Local preview bundle: `2.8.0`, arm64, deep/strict signature check passed;
  LICENSE and THIRD_PARTY_NOTICES present. Preview signing is ad hoc.
- `npm audit`: zero vulnerabilities.
- `cargo audit`: no vulnerability-class findings; 19 warnings. GTK3/glib and
  proc-macro-error are absent from the macOS target dependency tree. In particular,
  RUSTSEC-2024-0429 concerns the Linux glib path, not this macOS artifact.
  The macOS tree still includes unmaintained `ttf-parser`/`unic-*` and yanked
  `chacha20 0.10.1` through PDF/Tauri dependencies. Track upstream maintenance;
  this is not a claim of a warning-free dependency graph. No dependencies changed.
- Diff hygiene: added machine paths/secrets were not found; generated build,
  helper cache and node_modules files are not tracked.

## Remaining gates

- Native separate window → request → follow-up → main Diff → Apply → Undo.
- Real-model cancellation/retry, IME, VoiceOver, dirty-close and save-conflict smoke.
- Signed package validation and Apple processing remain distinct from the
  local preview build. Package provenance belongs in ignored
  `docs/internal/app-store-candidates/latest.json`.
- No v2.8 tag, GitHub Release, asset upload or App Store submission has been made.
  A source-only GitHub release must not imply a downloadable signed/notarized DMG.

## Candidate commands

```bash
npm ci
npm test
npm run smoke:app-store-surface
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml
npm run build
```

For the separately signed local package, configure the existing distribution
and installer identities as described in `../app-store-build.md`, then run
`npm run release:candidate -- --with-app-store-pkg --no-prune-pkgs`.
This prepares a local package; it does not upload it.
