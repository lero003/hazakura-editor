## 説明文

```text
Markdownで書き、本として読み、ローカルAIで整える。

Hazakura Editorは、Markdownやテキストの原稿を手元に置いたまま、書く・読む・直す・書き出す流れをつなぐMac向けエディタです。
メモ帳より賢く、IDEより静か。文章に向き合うための作業場を用意します。

■ Markdownで、静かに書く
Markdownを直接編集する画面と、文章に集中しやすいL Modeを切り替えられます。複数のタブ、アウトライン、検索・置換で長い原稿も行き来できます。表示を切り替えても、元のMarkdownを別形式へ書き換えません。

■ 本のように読み返す
プレビューや、ページ送り・見開き表示を備えた電子書籍モードで、同じ原稿を読み返せます。Book Scopeでは、選んだMarkdownの章をひとまとまりの本として読み、書き出せます。

■ 比べてから、変更を選ぶ
差分表示で変更前後を確認できます。保存時の競合や利用可能なバックアップも確認してから扱います。原稿への反映と保存は、自分で決める操作です。

■ ローカルAIと、必要なところだけ整える
Hazakura Local Assistは、対応環境で使えるオンデバイスの文章支援機能です。文書や選択範囲に対して校正、要約、翻訳などを依頼し、提案を差分で確認できます。
提案を自動反映・自動保存することはありません。反映後もUndoで戻せます。原稿を外部AIサービスへ送信せず、クラウドAIへの自動切り替えも行いません。
「オンデバイスモデル」画面でモデルの状態を確認できます。Apple Intelligenceモデルには、対応するMacと設定、言語・地域、モデルの準備が必要です。別途選ぶCore AIモデルには、macOS 27以降のApple Silicon Macと検証済みモデルが必要です。AIの提案は内容を確認してから採用してください。

■ EPUB・PDF・HTMLへ届ける
現在の文書やBook Scopeで選んだ章をEPUB・PDFへ書き出せます。EPUBには表紙を設定でき、現在のMarkdown文書は単体のHTMLへ書き出せます。EPUBの最終的な表示は、読むアプリによって異なります。

■ 自分の読み書きに合わせる
ライト・ダークや季節のテーマ、文字サイズなどを選び、原稿を読むときと書くときの見え方を整えられます。

■ 動作環境と通信について
macOS 26.0以降が必要です。Local Assistはプレビュー機能で、利用には対応する環境が必要です。文章の編集・読書・書き出しはAIを利用せずに行えます。アプリ独自のアカウント登録は不要です。
リモート画像は既定で読み込みません。モデルのダウンロード、許可したリモート画像の読み込み、外部リンクを開く操作では通信が発生する場合があります。
```

## 英語版とCore AI追記

英語の名前・副題・プロモーション文・説明・キーワード・What's Newは
[en-US JSON](../international-launch/app-store-en-US.json)を3.1へ更新した。
`publish_ready: false`のまま、英語UI / 画像 / Support・Privacy導線と実機の受入を待つ。
公式製品サイトは今回、日本語のままでもよい。公開Privacyの内容と実際の任意通信は一致させる。

Core AI配信の告知を加える場合は[リリースノート](3.1.0-app-store-release-notes.md)の条件付き文案を使い、
説明文にも対応OS・容量・メモリ条件を実配布情報と揃えて追記する。基本文案は
配信開始やCustom Modelsの一般向け取り込みを約束しない。未動作のUIを出荷してよいという判断ではない。

- この文案を現行Connectの説明と比較し、必要なサポート情報が抜けていないか確認する。

  「ローカルだからData Not Collected」と自動判定しない。
- 読み上げ用の言語情報改善を、全画面のVoiceOver受入済みという表現に置き換えない。
