This document is a human-readable transfer sheet, not an API payload or a record of changes already made in Connect.

## Description

```text
Write in Markdown. Read like a book. Make the next draft your own.

Hazakura Editor is a calm writing space for Mac, built around your Markdown and text files. Move from drafting to book-like reading, review your changes, and export when your work is ready.

WRITE WITH FOCUS
Edit Markdown directly or use L Mode for a quieter, single-pane writing experience. Keep your files in folders you choose, use multiple tabs, and move through your document with an outline and search.

READ THE BIG PICTURE
Read your work in an ebook-style view with a two-page spread. Bring selected Markdown chapters together in a Book Scope to read and export them as a book.

REVIEW BEFORE YOU KEEP
Compare changes, handle save conflicts, and review available backup snapshots before applying them. Your Markdown remains the source of truth. Choose which changes to apply and when to save.

EXPORT YOUR WORK
Export a document or selected book chapters to EPUB or PDF. Export the current Markdown document as standalone HTML. Add a cover to your EPUB when you need one.

REFINE ON YOUR MAC
On supported systems, Hazakura Local Assist offers on-device writing suggestions. Review a proposal before applying it to your document, then save when you decide. Local Assist does not send your writing to a cloud AI service or fall back to cloud AI. Check model status on the on-device models page. Review AI-generated text for accuracy before keeping it.

A LITTLE MORE PERSONAL
Choose light, dark, or seasonal themes, and adjust the text size for writing and reading.

REQUIREMENTS AND IMPORTANT DETAILS
Requires macOS 26.0 or later. Local Assist is a preview feature. The Apple Intelligence model requires a compatible Mac, supported language and region, Apple Intelligence enabled, and model readiness. A separately selected Core AI model requires an Apple silicon Mac running macOS 27 or later and a verified model. Writing, reading, and export do not require Local Assist.

Remote images are disabled by default. Downloading model assets, loading allowed remote images, or opening external links may use a network connection.
```

## What's New in This Version — 3.1.0

Use this only with a 3.1.0 submission after accepting the selected release candidate. This is the same English text as the [release notes](3.1.0-app-store-release-notes.md#whats-new-english).

```text
This update refines Local Assist and on-device model settings.

- See your target document or selection, suggested requests, and current model more clearly.
- Stop generation from the send control, with duplicate actions blocked while checking availability or switching models.
- View download and verification status, storage requirements, and memory requirements on the on-device models page.
- Improved keyboard focus after model selection and clearer messages when a local model is missing.
- Improved the English error-recovery screen and language information used by assistive technologies for app controls and document content.

AI proposals still require your review and explicit approval. Suggestions are not applied to your document automatically; saving is a separate choice. Local Assist availability depends on your Mac and selected model.
```

## Connect fields to verify separately

| Field or setting | Current decision for this packet |
| --- | --- |
| Primary Language | Preserve the current Connect setting. Adding en-US metadata is separate from changing Primary Language. |
