# 3.4.0 — テーマ演出の刷新と調整

Status: Local signed package verified; candidate GUI acceptance pending
Scope: Theme atmosphere S0〜S9 and regression fixes
Authority: Operational
Last reviewed: 2026-10-19

v3.3は審査提出済みとのオーナー報告（2026-10-19）を受け、テーマ刷新と直近の調整はv3.4.0へ分ける。
提出済みv3.3のbuild/source対応とApple側の現在の審査状態は独立未照合。
先に3.3.0として作成したテーマ入りpkgは旧ローカル候補として保持し、提出済み版と同一とは推定しない。

## 変更範囲

- 全7テーマの光・素材・組版と切替、江戸彼岸の花弁、夜光/曙光のcanvas粒子、深海の流れと光柱、
  CRTの走査線、テーマごとの保存✓を刷新した。light/darkの静けさは維持する。
- 演出の豊かさと一定の描画負荷を許容し、復帰停止、強度追従、60Hzでの品質回復、
  CRTの重複走査線と位相飛び、低モーション時に保存✓が消える不具合を調整した。
- Markdown source・保存形式・書き出し内容・実行/path/AI境界は維持し、依存を追加しない。
  紙面と日本語組版のCSSはL Mode/Readerにも適用する。

S9では上下バーへの演出到達、読む面の不透明紙、面全体を明るくするCSS合成を調整した。
追試で共通ebook/page-sheetの参照漏れ、深海ビネットの積層と明部の補助文字を修正。
全体試験はfrontend 3,094件・scripts 31件、Rust 515成功 / 4 ignored、両lane Vite・surface 137件が成功。
S9の最終署名pkgも本体/extensionの版・権限・署名・universal・notice・展開payload一致を再確認。旧4候補は保持。
隔離WKWebViewで前景を停止した透過検査により7テーマとReaderの紙色を白黒下地で照合した。動的全状態のAA適合は主張しない。

詳細は[テーマ演出計画](../theme-atmosphere-brushup-plan.md)と
[不具合調整・確認範囲](../reviews/2026-10-19-theme-regression-review.md)を参照する。
