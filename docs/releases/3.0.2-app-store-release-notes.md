## この版の位置づけ

公開済み 3.0 系に対する不具合修正版。`3.0.1`で直しきれていなかった
**macOSのメニューバーのちらつき**を修正した。新機能は足していない。
読み方・保存・書き出し・Local Assist の流れと、外部クラウドAIへ送らない境界は変えていない。

公開 build 番号と pkg のパス・SHA-256 は追跡ドキュメントへ固定せず、
`docs/internal/app-store-candidates/latest.json` を正本とする。このファイルには
提出・審査・公開の結果を書かない（結果が出たら追記する）。

## 掲載用（そのまま使う短縮版）

文字を入力するたびにmacOSのメニューバーがちらつく問題を修正しました。
設定などの画面を開いている間にメニューから表示を切り替えても、本文の状態とメニューの表示が食い違わないようにしました。

## このバージョンの変更（詳細文案）

入力中のちらつきと、メニュー表示の食い違いを直しました。

- **メニューバーのちらつき**: 文字を入力したり改行したりするたびに、macOSのメニューバーが
  一瞬描き直されてちらつくことがありました。入力のたびに起きていた不要な処理を止め、
  保存メニューの有効・無効など本当に変わったところだけを更新するようにしました。
- **メニュー表示と動作の一致**: 設定などの画面を開いている間は、メニューから
  表示の切り替え（プレビュー、行の折り返し、不可視文字、スペルチェック、えるモード）や
  テーマを選んでも、アプリの状態は変わりません。このとき、メニュー側のチェックや
  テーマの印だけが変わってしまうことがありました。表示と動作が必ず一致するようにしました。

Markdown source を正本とし、外部クラウドAIへの送信、auto-save、auto-apply、
background indexing を行わない境界は変わりません。

## TestFlight / 審査で確認すること

**最初に通す一本**: 保存済みの文書に1文字入力 → メニューバーがちらつかない →
保存メニューが有効になる → ⌘S で保存して無効に戻る → さらに数十文字とEnterを入力しても
ちらつかない（日本語IMEの変換中も同じ）。

- 設定画面を開いたままメニューから プレビュー／行の折り返し／不可視文字／スペルチェック／
  えるモード を選ぶ → 機能もチェックも変化しない。画面を閉じて選び直すと、両方が切り替わる。
- 設定画面を開いたままメニューからテーマを選ぶ → 何も起きない。閉じて選び直すと、
  テーマの印と実際の見た目が両方追従する。
- 未保存のタブと保存済みのタブを切り替えて、保存メニューの有効・無効が正しいこと。
- v3.0 から持ち越しの未受入: 日本語IME、保存衝突、再起動後の復元、VoiceOver、
  Local Assist の生成 → 停止 → 反映 → Undo。

不具合報告には OS 版、アプリ版/build、再現操作、期待と実際を記載してください。
個人原稿は不要です。可能なら内容を置き換えた短い再現用原稿を添えてください。

## 提出用メモ（掲載本文に含めない）

- この版は新機能なしの不具合修正版である。Core AI、MLX モデルの選択、Agent Workbench の
  App Store 露出、依存ライブラリの一括更新は含めていない。掲載文でも主張しない。
- Local Assist は従来どおりオンデバイスのプレビュー機能で、利用可否は Mac・macOS・
  Apple Intelligence の設定・言語・地域に依存する。審査で質問が来たときの説明もこの範囲に留める。
- 修正の内訳は `docs/current-work.md` の「3.0.2候補」節に残している。メニューの状態更新は
  差分適用になっており、全再構築は表示言語や最近使ったファイルが変わるときだけ。
- ローカルの最終候補は clean な commit から `release:candidate --with-app-store-pkg` で作り、
  `sourceDirty:false` と commit SHA を証跡として残す。署名 pkg の提出は人間操作。
- 3.0.1 はオーナーがストア申請済みと報告している。公開buildとの対応はこの記録では独立未確認。
