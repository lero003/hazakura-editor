# 3.2.1 — ワークスペース一覧の外部変更反映

Status: Candidate
Scope: Workspace file list refresh and local package checkpoint
Authority: Operational
Last reviewed: 2026-10-12

外部でファイルを追加・削除・名前変更しても、ワークスペースを開き直さず一覧へ反映する。
通常のファイル一覧とL Modeのフォルダ表示で、アプリ復帰時と表示中の10秒間隔で確認する。
手動の「ワークスペースを更新」も追加する。

対象は選択済みrootと展開中のフォルダの直下一覧。本文解析・全文索引・OKF再実行は行わない。
既存の子一覧を保持した差し替えでフォルダの展開・選択・スクロールを維持し、変更がないときは
既存stateを再利用する。名前変更や削除確認中、ファイル一覧非表示、ウィンドウ非表示時は停止する。
古いworkspace・古い要求の応答を破棄し、同期途中の取得失敗では既存一覧を保持して次回再試行する。

本文は既存の外部変更／衝突処理を維持し、一覧から消えたpathでも開いている未保存原稿は閉じない。
複数Macでは、既存同期サービスからこのMacへ届いた変更を表示する。同期そのものの追加ではない。
npm・Cargo・Tauriの版数は3.2.1、依存とCore AI runtimeは変更しない。

  Reader非表示時の停止も失敗を再現して修正した。DOM上の検証はmacOS描画の実機確認とは区別する。

`docs/internal/app-store-candidates/latest.json` を正本とする。作成時の署名と収録内容をローカルで確認する。

## 実機受け入れ

- Finderから直下と展開中の子フォルダへ追加・削除・名前変更し、復帰時／10秒後に反映する。
- 更新後も展開・選択・スクロールとキーボードfocusが続く。
- 名前変更中と削除確認中は入力・確認を邪魔しない。閉じた後は確認を再開する。
- 未保存原稿を他のMacで変更したときは衝突確認を維持する。外部削除・移動でも原稿を失わない。
- 同期途中の一時消失、スリープ復帰、workspace切替、L Modeの表示切替を確認する。
- VoiceOverで更新ボタンに到達して実行できる。

Apple送信、TestFlight、実機受け入れ、公開はローカルsource／pkg検証とは別ゲート。
