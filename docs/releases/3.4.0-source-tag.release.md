# Hazakura Editor v3.4.0 — テーマ演出の刷新

`v3.4.0` は、現在の実装を固定するGitHubのソースチェックポイントです。
リポジトリのソース、タグ、GitHub標準のソースアーカイブ、ビルド手順を公開します。
pkg / DMGなどのバイナリは添付しません。

## 変更

- 全7テーマの光・素材・動き・切替を調整し、テーマごとの保存フィードバックを追加
- 江戸彼岸: 花弁の奥行き・共通の風・枝の揺れ、紙面の朝の光
- 夜光・曙光: DOM粒子をcanvasへ移し、奥行き・明滅・ポインタ視差を追加
- 深海: 時間差に追従する流速場、水面光・紙面の深度・左右の前景ボケ
- CRT: 走査線をデバイスpx基準へ統一し、蛍光ブルーム・RGBグリル・ガラス面を追加
- プレビュー背景の上書き、CRTの非アクティブ時の描画、花弁の裏返りの停止漏れを修正

Markdown source・保存形式・書き出し内容・実行/path/AI境界は維持しています。
前回のGitHubソースタグ `v3.0.0` 以降の、v3.1〜v3.3のLocal Assist・モデル管理、
ワークスペース追従、依存整理、保存・文字コード・書き出しの修正も含むチェックポイントです。
詳細は[v3.4の記録](3.4.0-theme-atmosphere.md)、[v3.3の記録](3.3.0-dependency-autonomy.md)、
[v3.2.1の記録](3.2.1-workspace-refresh.md)を参照してください。

## 残る確認と既知の制限

今回の公開は、実装レビューとローカル検証を済ませたソースを固定するものです。
署名候補GUI、実CodeMirrorでの日本語IME・長文、Retina/DPR変更、L Mode/Readerの実機受け入れ、
Intel/macOS 26のGUI、VoiceOverは未確認です。App Store公開・審査通過・全実機受入を示しません。

production npm監査は0件。全npm監査では開発専用のhigh 2件を残しています。
`source-map-js@1.2.1` の細工されたsourcemapによるDoSは[既存の評価](../reviews/2026-10-18-v3.3-regression-review.md#監査と残す条件)を維持します。
`vite@8.3.1` に追加された[Windowsでのlaunch-editorの問題](https://github.com/advisories/GHSA-587h-7wmj-h5pm)は、
macOSの製品実行経路には該当しません。関連する[Windowsの引数処理](https://github.com/advisories/GHSA-698v-4r3x-3vcv)と
[Vite利用時はWSLを条件とする問題](https://github.com/advisories/GHSA-r825-w8mm-5pxw)も開発ツール側の制限として記録します。
Viteはdev依存で、開発サーバーは `127.0.0.1` に限定しています。依存更新はこのチェックポイントに混ぜず、
既存の更新PRで別途確認します。Cargo監査は検出vulnerabilityなし、既存の許容warning 8件を維持します。

## ソースからのビルド

```bash
npm ci
npm run build
```

これはローカルプレビューのビルドです。Developer / GitHubレーンは `npm run build:developer-preview` を使います。
前提条件と配布レーンは[README](../../README.md)と[App Store build](../app-store-build.md)を参照してください。
既存の公開タグ・アセットは変更しません。
