## App Store Connect Copy

### Japanese

Hazakura Editor 2.6では、このMac上のLocal Assistで文章を会話しながら整え、差分を確認してから本文へ反映できるようになりました。生成中は原稿を書き換えません。反映と保存は別の明示操作です。外部のクラウドAIには送りません。

・会話は別ウィンドウ、差分確認と「文書へ反映」は本ウィンドウにあります。追加の指示は、まだ反映していない案だけを更新します。
・ワークスペース、編集領域、プレビュー／参照の幅を、原稿や作業に合わせて調整できます。ドラッグとキーボードに対応し、幅はこのMacのアプリ内に保存します。Markdownやプロジェクトフォルダには書き込みません。
・テキストの参照表示は、既存のプレビュー文字サイズ設定に合わせます。大きなフォルダでは、表示上限を超えて非表示になった件数を明示します。
・プレビューでは、画像の読み込みで本文がちらつきにくくなり、長い文書でもマウス選択しながら端までスクロールできます。テーマを切り替えても、読む面のコントラストを保ちます。
・参照で原稿を横に開いたまま「確認」や参照内の「差分」を押すと、差分が表示されます。参照の読み込みは残ります。プレビューや電子書籍との切り替えでも、右列が空になりません。
・PDF、HTML、EPUBの書き出しでは、準備中の状態と完了先を示し、完了したファイルをFinderに表示します。Bookの章立ては引き続きこのMacのアプリ内に保存され、フォルダやOKFの順序を自動変更しません。

Markdown sourceを正本とし、background indexing、auto-save、auto-apply、縦書きを行わない境界は変わりません。

### English

Hazakura Editor 2.6 lets you refine prose with on-device Local Assist: converse about the current passage, review a Diff, and apply only when you choose. Generation does not rewrite the manuscript. Apply and Save stay separate explicit actions. Local Assist does not send text to a cloud AI.

- Conversation lives in a companion window; Diff review and Apply live in the main window. Follow-up instructions update the unapplied proposal only.
- Resize the Workspace, editor, and Preview or Reference areas to fit the manuscript. Separators support pointer and keyboard control. Widths are remembered locally in the app, not written to Markdown or the project folder.
- Text Reference follows the existing Preview font-size setting. Large folders show the exact number of entries hidden by the per-folder display limit.
- Preview keeps the reading surface steadier while nearby images load, and long documents can be mouse-selected with edge auto-scroll. Theme changes keep reading contrast.
- Review changes, or View diff from a text Reference, now shows Diff instead of an empty right column. The loaded Reference stays retained. Switching Preview, e-book, Outline, or Diff from Reference keeps the chosen pane visible.
- PDF, HTML, and EPUB export continue to show preparation and destination feedback and reveal the completed file in Finder. Book chapter order remains app-private and does not rewrite folder or OKF order.

Markdown remains the source of truth. Background indexing, auto-save, auto-apply, and vertical writing are unchanged non-goals.

## Boundary

- Hazakura Local Assist remains on-device, availability-gated, and preview-shaped. It has no network fallback, tool calling, workspace-wide indexing, or autonomous apply.
- Generation does not mutate the editor buffer. Only the explicit Diff Apply action writes the reviewed proposal, and that write does not save.
- Workspace and pane widths are app-private. They do not rewrite Markdown or the project folder.
- Book chapter order remains app-private and separate from OKF semantics.
- Safe Editor remains primary. The App Store lane omits Agent Workbench, CLI Agent, arbitrary command execution, and external AI/API providers.

## Explicit Non-goals

- vertical writing (縦書き)
- Core AI model catalog / download
- auto-apply, auto-save, background indexing
- Agent Workbench in the App Store lane
- claiming the detached-window physical Assist gate has passed

## Product Promise

Markdownで書き、本として読み、ローカルAIで整える — 会話で案を育て、差分を見てから本文へ反映し、原稿の幅と読みやすさを手元で整えられる段階です。説明は Help に置き、画面に機能を並べすぎません。
