## このバージョンの変更

画面全体を整え、書く・読む・書き出す流れを分かりやすくしました。

- **電子書籍（見開き）**を読みやすくしました。紙面として表示し、見開きの間隔を詰め、
  読書位置の進捗を示します。ページの前後・目次・編集への戻りは画面下にまとめました。
- **江戸彼岸**テーマを明るい紙面へ刷新しました。木漏れ日の下で読むような、明るく落ち着いた配色です。
- **アシスト（下書きの提案）**を本文の画面で確認できるようにしました。
  提案は差分で確認し、採用したいときだけ本文へ反映できます。反映したあとは取り消せます。
  提案を確認している間、背後の本文は編集できません（見えていない文章に書き込まないため）。
- **書き出し**は、同じ画面で EPUB / PDF / HTML を選べるようにしました。
  書名などの入力と「書き出す範囲」は、形式を切り替えても保たれます。
- **検索**は、一致した箇所が分かるように強調し、ファイルごとの件数を表示します。
  絵文字を含む行でも一致位置が正しく表示されます。
- **画像プレビュー**に倍率（25%〜400%）を追加しました。「全体を表示」は縦長の画像でも全体が収まります。

Local Assist の提案は、意味や固有名詞が正しいかも確認してください。
利用にはApple Intelligence対応Macが必要です。

## TestFlightで確認すること

- 見開き表示: ページの前後移動、目次、下部の操作帯、低い窓（640px前後）での見え方。
- アシスト: 提案の差分確認 → 反映 → Undo。「案を残して編集に戻る」で提案が残ること。
  提案を見ている間に背後の本文へ入力できないこと。
- 書き出し: EPUB / PDF / HTML の切替で入力と範囲が保たれること、実際の出力内容。
- 検索: 絵文字・補助面漢字を含む行の一致表示、長い行の後方一致、件数の表示。
- 画像プレビュー: 巨大・縦長・破損・透明画像、権限のない画像。
- テーマ（江戸彼岸を含む7種）、えるモード、狭い窓、200%文字、VoiceOver、日本語IME、再起動後の復元。
