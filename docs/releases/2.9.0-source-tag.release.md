署名pkgは準備中。既存のv2.8候補の証跡を流用しない。

- App Store surface **10 files・111 tests** 成功。

- Swiftは書込可能なmodule cacheと `--disable-sandbox` を指定して再実行。
  通常sandbox下のcache書込失敗を試験成功へ数えていない。

- npm audit: 指摘0件。
- cargo audit: vulnerability分類0件。保守停止・unsound・yankedの警告あり。
