## このバージョンの変更

日々の執筆で使う、保存・復旧・検索・書き出しを改善しました。

- 別名保存の処理中に入力した文章が残るようにしました。
- 元ファイルが変更・移動された場合も、下書きを別の未保存タブへ取り出せるようにしました。
- 未保存の文書を「保存して閉じる」操作を修正しました。
- 一部のUnicode文字を含む検索と、文字コードを指定した開き直しを改善しました。
- ファイル操作後のバックアップ警告と、PDF・HTMLの画像欠落通知を改善しました。
- Local Assistの校正で数字やMarkdown構造が変わった候補を検出し、再依頼できるようにしました。

Local Assistの提案は差分で確認し、採用したいときだけ本文へ反映できます。
意味や固有名詞が正しいかも確認してください。利用にはApple Intelligence対応Macが必要です。

## TestFlightで確認すること

- 別名保存中の入力、未保存文書を保存して閉じる、次回起動での単独ファイル復元。
- 元ファイルを外部で変更・移動した後の下書き取り出し。
- UTF-8/BOM・Shift-JIS・EUC-JPでの読込・保存・指定文字コードでの開き直し。
- 改名・移動・ゴミ箱、画像を含むPDF/HTMLの最終出力と警告。
- 日本語IME、VoiceOver、テーマ、長文、対応範囲の旧OSでの通常編集。
- Local Assistの校正・追加指示・停止・再依頼・差分確認・反映・Undo。
