## この版の位置づけ

公開済み 3.0 系に対する不具合修正版。編集面のスクロールバーについて 2 件直した。
右ペインを開いているとき **スクロールバーを右端でつかむとスクロールできない**
（代わりにペイン幅の変更が始まる）問題と、**一気に一番下までドラッグすると
表示が末尾の少し上で止まる**問題。1 文字も本文を書き換えず、`source` を正本とする
境界は変えていない。新機能は足していない。

公開 build 番号と pkg のパス・SHA-256 は追跡ドキュメントへ固定せず、
`docs/internal/app-store-candidates/latest.json` を正本とする。このファイルには
提出・審査・公開の結果を書かない（結果が出たら追記する）。

## 掲載用（そのまま使う短縮版）

プレビューを開いているときに、本文の右端にあるスクロールバーをつかんでも
スクロールしないことがある問題と、一番下までドラッグしても末尾の少し上で
止まってしまう問題を修正しました。

## このバージョンの変更（詳細文案）

**スクロールバーのつかみ位置を直しました。**

- 本文の右隣には、本文とプレビューの幅を調整する細い領域があります。その
  「つかむための透明な範囲」が本文側へ 4px 重なっていたため、本文のいちばん右端で
  スクロールバーをつかむと、スクロールの代わりにその領域が反応していました。
  縦にドラッグしても何も起きず、少し横に動かすとペイン幅が変わってしまう状態です。
- 重なりを右側だけに限り、本文の右端でつかんだときは必ずスクロールバーが反応する
  ようにしました。つかむ幅は 10px 確保しています。
- 同じ構造のファイル一覧（サイドバー）の右端でも同様に直っています。
- 一気に一番下まで引いたときに末尾で止まらず少し上へ戻っていたのは、行の高さを
  測り直すタイミングと、プレビュー側の古いスクロール位置が本文へ書き戻される
  タイミングが重なっていたためです。末尾まで引いたときは、測り直した後も
  末尾に留まるようにしました。
- 検索の「1件置換」で、置換した次の一致を飛ばしてしまう問題を修正しました。
  置換した位置の次から、次の一致を選び直します。
- 文章生成（Local Assist）中は編集をロックしていますが、その間に検索の置換を
  行うと画面上の本文だけが変わって保存対象と食い違うことがありました。ロック中は
  置換を止め、検索だけ使えるようにしました。

読み方・保存・書き出し・えるモード・Local Assist の流れと、外部クラウドAIへ
送らない境界は変えていません。

## TestFlight / 審査で確認すること

**最初に通す一本**: 文書を開き、右ペインにプレビューを出す → 本文の右端の
スクロールバーをつかんで上下にドラッグ → 本文がスクロールし、ペイン幅は変わらない。

- 同じスクロールバーを**一気に一番下まで**引いて離す → 末尾（最後の行）で止まり、
  少し上へ戻らない。続けて上へドラッグすると、動かした位置で止まる。
- つまみの**上寄り・中央・下寄り**のどこをつかんでも、一番下まで運べば末尾で止まる。
  トラックの途中で離したときは末尾へ勝手に寄らない。
- つかむ位置を少し内側（右端から 8px 程度）にしても同じくスクロールする。
- 検索で `foo` を3つ含む行を用意し、1件置換 → 次の一致が2番目（飛ばさない）。
  置換語にも検索語を含める場合と、最後の一致を置換する場合も確認する。
- Local Assist の生成中に検索バーで置換 → 何も変わらない（置換ボタンは無効）。
  生成が終わると置換できる。
- 本文とプレビューの境目の細い線をつかんで左右にドラッグ → ペイン幅が変わる
  （こちらは従来どおり）。
- ファイル一覧の右端のスクロールバーでも同じことを確認する。
- 右ペインを閉じた状態でも、本文のスクロールバーが普通に動く。
- v3.0 から持ち越しの未受入: 日本語IME、保存衝突、再起動後の復元、VoiceOver、
  Local Assist の生成 → 停止 → 反映 → Undo。

不具合報告には OS 版、アプリ版/build、再現操作、期待と実際を記載してください。
個人原稿は不要です。可能なら内容を置き換えた短い再現用原稿を添えてください。

  Apple Intelligence の設定・言語・地域に依存する。審査で質問が来たときの説明も
  この範囲に留める。
