## 変更範囲

- **風景として組む。** 空（昼前の青から地平の暖色へ）・草原・一本の江戸彼岸・舞う花弁を
  three.js で描く。画像の枝を板ポリで揺らすのをやめ、木は骨格から起こす
  （`src/features/theme/edohiganTree.ts`）。決定的な種から毎回同じ木になる。
- **枝は曲線。** 各枝を二次ベジェに曲げ、根元は根張りで地面へ広がる。樹皮は UV の
  ノイズでムラを付け、太陽側の縁だけを淡く起こす（逆光のリム）。
- **花は 5 弁のスプライト。** 花弁画像を 3 方向へ重ねるのをやめ、canvas に描いた
  5 弁の花をテクスチャにする（外部 fetch なし）。約 3,000 枚を 1 ドローコールで置く。
  枝先だけでなく枝の途中にも付くので、樹冠の内側が空かない。
  本数を増やして塊を大きくし、満開の枝が「黒い枝に点」ではなく面に見えるようにした。
- **遠景の林。** 2 層の帯に分け、手前ほど暗く輪郭を細かくした。梢の粒を足して
  「木の並び」に見えるようにした。
- **舞う花弁。** 画面全体へ一様に散らすのをやめ、木のまわりへ寄せた。
- **地面。** 近景の濃い緑から遠景の霞へ。木の根元には楕円の影を落とし、
  地平の向こうに低い林の帯を置く。地面は 2400 単位まで広げ、地平の継ぎ目を消した。
- **草原の草。** 地面の板が「塗った緑」に見えないよう、株ごとにまとめた草を
  4,200 本敷く。画面下端の外には大きな草を 20 本だけ置いて前景の枠にした。
- **空の雲。** 5 オクターブの FBM をゆっくり流す。太陽の側は暖かく、下側は灰色。
- **仕上げ（ポスト）。** 深度から被写界深度を作り（ピントは木、遠景と足元はぼける）、
  明部のブルーム、寒暖のグレーディング、粒子、ビネットを 1 フレームに重ねる。
  表示色に対してはフィルミックな肩ではなく smoothstep のコントラストで整える。
- **花の影。** 花も影パスへ入れ、ライトを向いた板として樹冠の影を落とす。
  地面には枝の影と花の影が重なり、木漏れ日の斑になる。
- **カメラの漂い。** 周期 2〜3 分のごくゆっくりした前後のドリーと縦の揺れ。
  前景の草と木のあいだに視差が出て、止め絵ではなく回っている映像に見える。
  横にはほとんど動かさない（位相によって幹が本文へ重なるのを避けるため）。
  強度 `subtle` では振幅が半分。
- **狭い窓。** アスペクトが 1.45 未満のときは木を右へ寄せ、少し縮める。
- **木の影。** ライト視点で木のシルエットを 1024px の的へ描き、地面がそれを 9 タップで
  ぼかして受け取る。木と同じ風の uniform を共有するので、影も一緒に揺れる。
  根元の楕円影と、樹冠のムラ（葉の影）を重ねて、一枚の黒い板に見せない。
- **樹冠の自己遮蔽。** 花ごとに「樹冠の外側か内側か」を持たせ、内側を 0.52 倍まで沈める。
  奥の花と梢の花で明るさが変わり、塊に厚みが出る。
- **光条（ゴッドレイ）。** 明部のうち太陽と枝の隙間から漏れる強い光だけを源にし、
  太陽へ向かって 24 ステップ積む。木を抜けた光の筋が画面に出る。
- **花の密度ムラ。** 枝ごとに「咲きぶり」を持たせ、満開の枝と咲き始めの枝を混ぜた。
  花の量と大きさが枝ごとに変わる。
- **手前の草を束ねる。** 1 インスタンス = 高さと傾きの違う 3 枚の葉にした。
- **花の向き。** 花ごとに樹冠中心からの法線を持たせ、太陽との角度で明暗を付ける。
  樹冠の右側が陽を浴び、左側が沈む。
- **草原の色ムラ。** 大きなスケールのノイズで枯れ草と土の窪みを混ぜ、一様な緑を崩した。
- **花の傾き。** 全部が正面を向くと貼り紙に見えるので、花ごとに縦を 55〜100% へ潰して傾ける。
- **樹皮。** 四角い斑になっていた `floor()` のノイズを、縦に伸びる滑らかな
  3 オクターブのノイズへ置き換えた。
- **草の形。** 株ごとに幅と傾きを変え、同じ型を並べた印象を消した。
- **被写界深度の調整。** ピント面を広げ、草原が「全部ぼけた背景」にならないようにした。
- **太陽。** 芯とアナモルフィックな筋を空へ置き、木の枝の向こうで白く飛ばす。
- **風が梢を渡る。** 揺れの位相にワールド座標を混ぜ、木の左端と右端で
  タイミングをずらした。1 本の木が一斉に傾くのではなく、風が抜けていく。
- **樹冠のムラ。** 花の塊を寄せ、個体ごとに明るさを散らした。
- **揺れは 1 つの風。** 根元からの距離を重みにし、幹はほぼ動かず枝先だけがしなる。
  枝ごとに位相をずらしてあるので、木全体が同じリズムで回ることはない。
  花は枝先と枝の途中にインスタンスで置き、木と同じ式で揺れる。
- **文字の面は「紙」ではなく霞。** 横方向の `linear-gradient` で本文の帯だけを
  明るくし（中央 0.62）、右の木と下の草原を残す。読む面（`--surface-paper-solid`）は
  不透明のまま。背景をぼかす `backdrop-filter` は使わない（木が消えるため）。
- **three.js 0.186.1 を追加。** 動的 import なので main バンドルには入らない。
  テーマを江戸彼岸にしたときだけ別チャンクを読む。main の増分は約 26 kB（+1.5%）。
- **強度が情景に効く。** これまでは舞う花弁の枚数だけだった。`subtle` は風 0.5 倍・
  時間 0.78 倍・花 62%・草 55%、`normal` は 1 倍・85%・80%、`dramatic` は
  風 1.55 倍・時間 1.12 倍・全部。静かに読みたい人と眺めたい人で差が出る。
- **既定で有効。** 無効化は `?edohigan3d=0` または `VITE_HAZAKURA_EDOHIGAN_SCENE=0`。
  WebGL2 が無い環境では背景を描かず、紙の不透明な面（v3.4.0 の見え方）へ戻る。
- 花弁は背景のシーン内だけに置く（紙の上の乗算レイヤーは廃止）。緑の草原の上で
  乗算した花弁が「汚れ」に見えたため。深さはシーン内の z で付ける。
- 強度（off/subtle/normal/dramatic）、実測フレーム時間による品質段、`prefers-reduced-motion`、
  非表示・非フォーカス時の停止は既存の ambient 予算系をそのまま使う。
  reduced-motion では静止画 1 枚だけを描く。

## 追補 — 光の向き・樹皮・影（2026-10-22 続き）

情景の骨格は変えず、**光の整合・木の質感・影の落ち方**だけを詰めた。
本文の紙（霞）・文字色・保存形式・実行/path/AI 境界は変えていない。

- **光を 1 つに。** 空の太陽は右上・木の奥なのに、木だけ手前左から照らされていた
  （逆光の縁が太陽と反対側に出て、円柱にスタジオ照明を当てたように見えた）。
  `src/features/theme/edohiganLighting.ts` の `EDOHIGAN_SUN_DIRECTION` を
  木・花・地面の影カメラで共有し、向きの食い違いを再発させない。
- **樹皮を桜のものへ。** 縦縞ノイズをやめ、横へ走る皮目（lenticel）と縦のひびの 2 層に。
  樹皮 UV を枝の実寸（m）で持たせ、太い幹と細い枝で模様の密度が変わらないようにした。
- **根張り。** 幹の断面を 3 ローブにし、0.45 だけ地面へ沈めた。地面と接する線が根の形になり、
  「円錐を置いた」切れ目が消える。管メッシュは 9 面 × 6 輪へ増やし、幹と太枝の角を減らした。
- **影を花の形で抜く。** 花の影は板の四角いまま落ちていた（地面に四角い影が並ぶ）。
  テクスチャの alpha で discard し、影のブラーを 4 テクセルへ広げ、テクスチャ外周を 0 へ
  落として直線の切れ目を消した。影は黒ではなく空の青をわずかに返す。
- **見た目で確認したこと。** 木の右縁が暖かく、左面が沈む。幹の根元が草に埋もれ、
  地面の影は枝と花のムラを持ちながら左下へ伸びる。粒状の四角い影は消えた。

## 追補2 — ノスタルジックな構図と「読みの霞」（2026-10-22 続き）

## 追補3 — 樹形・付着する花・光学のコードレビュー（2026-10-22）

「遠くの一本」と読みの霞を維持し、形と動きの不整合を修正した。

- **樹皮の表裏とねじれ。** 管メッシュの三角形が内向きで、外側ではなく内壁が見えていた。
  winding を外向きへ修正し、曲がりの途中で断面の軸が切り替わるねじれも除去。
  メッシュ生成を `edohiganTreeGeometry.ts` へ分け、実際の全三角形の向きと断面中心を検査する。
- **枝と花をつなぐ。** 親子の枝が接点でも別位相で動き、途中の花まで最大振幅・別周期で
  揺れていた。位置と根元からの距離による共通変位へ揃え、花は枝上の基点の動きに追随する。
  花の配置と管の生成は同じベジェ曲線を使い、曲がった枝から花が浮くずれも減らした。
- **ブルーム。** 1×1 で初期化したサイズがぼかし幅に残っていたため、近傍画素ではなく
  画面端を拾っていた。現在の半解像度 target のサイズから毎回計算する。
- **影の角度。** 樹冠へ注視点を上げたぶん、影カメラの方向が共有の太陽方向からずれていた。
  光源位置と注視点の基準を揃え、木・花の陰影と地面への投影の方向を一致させた。
- **静止表示の更新。** reduced-motion 時も窓の resize・強度変更・非同期テクスチャ読込完了を
  反映する。連続描画は開始せず、破棄後の遅延読込は無視する。

## 追補4 — 実アプリの3ペイン・読みの実測とマウス追従（2026-10-22）

  前回の 1280×800 の 75fps とは条件が違う。
  ポインタ left/right のフィクスチャで樹冠が約 20〜30px 動くことを確認した。

## 追補5 — 花のピントと、作り込みが見える階調（2026-10-22）

最新の3ペインを隔離 WKWebView で撮り直し、細部を隠していた原因を修正した。
追補4の縦の読みの霞・マウス追従は維持する。

- **花にもピントを合わせる。** 半透明の花は深度を書いておらず、被写界深度が花の後ろの
  空や地面を参照していた。同じ geometry / uniform で花形だけの深度を先に描き、色は別に
  柔らかい透過の縁を残す。板の四隅は深度へ入れない。花の影も同じ alpha 条件へ揃えた。
- **強度を下げても片側を裸にしない。** 花は枝を辿った配列の先頭だけが残っていた。
  配置とは別の固定乱数で描画順を混ぜ、normal の4象限残存比を63.3〜100%から82.7〜86.4%へ。
  default の花3,818枚・枝482本と花の位置・風の基点は変えていない。
- **花を支える枝。** 幹と主枝は保ち、depth4以降の末枝だけ細くした。最深枝の根本半径は
  約38%、先端は約51%減。親子の接点の太さは一致する。梢を黒く沈める量も緩めた。
- **花の輪郭。** 同じ128pxの手続きスプライトに浅い切れ込みと丸い肩、淡い蕊を持たせた。
  樹冠は上に空の余白を残す大きさ（`TREE_SCALE` 1.10→1.02）へ調整。
- **白い霞を整理。** 光条は空の明部全体ではなく太陽の近傍から積む。Previewは外側0.22・
  本文の下0.65へ配分（合成約0.73）、16pxの余白で風景を見せ、blurは12→5px。
  編集本文の霞と文字色、電子書籍/Readerの不透明紙、source/保存/書き出し内容は維持する。

検証: frontend **341 files / 3,175 tests**・scripts **31件**、typecheck、
`npm run build:vite`（Developer bundle boundary）、`git diff --check` が成功。
花の間引き・末枝の連続性・花の深度・光条の画面比は失敗テストを先に確認して修正した。
隔離 WKWebView 1537×912 / DPR1で1 canvas、強度切替とoffのcanvas 0、console errorなし。
1100×780の3ペインも別途撮影し、同じ強度切替・canvas枚数・console errorなしを確認した。
情景の描画呼出回数は normal **37.5** / dramatic **75.3** / subtle **25.0** 回/秒で、
今回変更前の37.5 / 75.2 / 25.0と同程度。ページrAFやGPU描画完了の計測とは区別する。
文字の近傍7pxの背景から推定した局所コントラストの1パーセンタイルは

- 隔離 WKWebView（1280×800 / 900×700 / 1600×1000、DPR1、非永続）で 1 canvas・強度 4 段を採取:
  ページ全体の rAF 間隔は1280×800で normal 75.0 / dramatic 74.4 / subtle 73.4 / off 74.0 fps
