# 3.4.1 — 江戸彼岸の情景（three.js 二層）

Status: リリース候補。タグ・pkg は未作成
Scope: 江戸彼岸テーマの描画刷新（presentation 層のみ）
Authority: Operational
Last reviewed: 2026-10-22

江戸彼岸を「和紙の上の花」から「草原に立つ一本の大木」へ移した。
Markdown source・保存形式・書き出し内容・実行/path/AI 境界は変えていない。
対象は `src/styles/edohigan-theme.css` と ambient / overlay の presentation 層。

## 変更範囲

- **風景として組む。** 空（昼前の青から地平の暖色へ）・草原・一本の江戸彼岸・舞う花弁を
  three.js で描く。画像の枝を板ポリで揺らすのをやめ、木は骨格から起こす
  （`src/features/theme/edohiganTree.ts`）。決定的な種から毎回同じ木になる。
- **枝は曲線。** 各枝を二次ベジェに曲げ、根元は根張りで地面へ広がる。樹皮は UV の
  ノイズでムラを付け、太陽側の縁だけを淡く起こす（逆光のリム）。
- **花は 5 弁のスプライト。** 花弁画像を 3 方向へ重ねるのをやめ、canvas に描いた
  5 弁の花をテクスチャにする（外部 fetch なし）。約 3,000 枚を 1 ドローコールで置く。
  枝先だけでなく枝の途中にも付くので、樹冠の内側が空かない。
  本数を増やして塊を大きくし、満開の枝が「黒い枝に点」ではなく面に見えるようにした。
- **地面。** 近景の濃い緑から遠景の霞へ。木の根元には楕円の影を落とし、
  地平の向こうに低い林の帯を置く。地面は 2400 単位まで広げ、地平の継ぎ目を消した。
- **草原の草。** 地面の板が「塗った緑」に見えないよう、株ごとにまとめた草を
  4,200 本敷く。画面下端の外には大きな草を 20 本だけ置いて前景の枠にした。
- **空の雲。** 5 オクターブの FBM をゆっくり流す。太陽の側は暖かく、下側は灰色。
- **仕上げ（ポスト）。** 深度から被写界深度を作り（ピントは木、遠景と足元はぼける）、
  明部のブルーム、寒暖のグレーディング、粒子、ビネットを 1 フレームに重ねる。
  表示色に対してはフィルミックな肩ではなく smoothstep のコントラストで整える。
- **木の影。** ライト視点で木のシルエットを 1024px の的へ描き、地面がそれを 9 タップで
  ぼかして受け取る。木と同じ風の uniform を共有するので、影も一緒に揺れる。
  根元の楕円影と、樹冠のムラ（葉の影）を重ねて、一枚の黒い板に見せない。
- **樹冠の自己遮蔽。** 花ごとに「樹冠の外側か内側か」を持たせ、内側を 0.52 倍まで沈める。
  奥の花と梢の花で明るさが変わり、塊に厚みが出る。
- **花の傾き。** 全部が正面を向くと貼り紙に見えるので、花ごとに縦を 55〜100% へ潰して傾ける。
- **樹皮。** 四角い斑になっていた `floor()` のノイズを、縦に伸びる滑らかな
  3 オクターブのノイズへ置き換えた。
- **草の形。** 株ごとに幅と傾きを変え、同じ型を並べた印象を消した。
- **被写界深度の調整。** ピント面を広げ、草原が「全部ぼけた背景」にならないようにした。
- **太陽。** 芯とアナモルフィックな筋を空へ置き、木の枝の向こうで白く飛ばす。
- **風が梢を渡る。** 揺れの位相にワールド座標を混ぜ、木の左端と右端で
  タイミングをずらした。1 本の木が一斉に傾くのではなく、風が抜けていく。
- **樹冠のムラ。** 花の塊を寄せ、個体ごとに明るさを散らした。
- **揺れは 1 つの風。** 根元からの距離を重みにし、幹はほぼ動かず枝先だけがしなる。
  枝ごとに位相をずらしてあるので、木全体が同じリズムで回ることはない。
  花は枝先と枝の途中にインスタンスで置き、木と同じ式で揺れる。
- **文字の面は「紙」ではなく霞。** 横方向の `linear-gradient` で本文の帯だけを
  明るくし（中央 0.62）、右の木と下の草原を残す。読む面（`--surface-paper-solid`）は
  不透明のまま。背景をぼかす `backdrop-filter` は使わない（木が消えるため）。
- **three.js 0.186.1 を追加。** 動的 import なので main バンドルには入らない。
  テーマを江戸彼岸にしたときだけ別チャンクを読む。main の増分は約 26 kB（+1.5%）。
- **強度が情景に効く。** これまでは舞う花弁の枚数だけだった。`subtle` は風 0.5 倍・
  時間 0.78 倍・花 62%・草 55%、`normal` は 1 倍・85%・80%、`dramatic` は
  風 1.55 倍・時間 1.12 倍・全部。静かに読みたい人と眺めたい人で差が出る。
- **既定で有効。** 無効化は `?edohigan3d=0` または `VITE_HAZAKURA_EDOHIGAN_SCENE=0`。
  WebGL2 が無い環境では背景を描かず、紙の不透明な面（v3.4.0 の見え方）へ戻る。
- 花弁は背景のシーン内だけに置く（紙の上の乗算レイヤーは廃止）。緑の草原の上で
  乗算した花弁が「汚れ」に見えたため。深さはシーン内の z で付ける。
- 強度（off/subtle/normal/dramatic）、実測フレーム時間による品質段、`prefers-reduced-motion`、
  非表示・非フォーカス時の停止は既存の ambient 予算系をそのまま使う。
  reduced-motion では静止画 1 枚だけを描く。

## 検証

- frontend: **336 files / 3,146 tests**、typecheck、`npm run build:vite`（bundle boundary 込み）。
- 隔離 WKWebView（1280×800 / 900×700 / 1600×1000、DPR1、非永続）で 1 canvas・強度 4 段を採取:
  normal 75.0 / dramatic 74.4 / subtle 73.5 / off 73.8 fps（p95 15〜16 ms）。
  ポスト処理（深度・ブルーム・グレーディング）込みでこの数値。
  狭い窓でも文字の帯と木の位置は破綻しない。off で canvas 0 枚。
- 動きの確認: 1.2 秒離した 2 枚で全画面の 12.2% が変化。木は幹がほとんど動かず
  梢だけがしなる。`subtle` と `dramatic` の画面差は 11.9%（樹冠 46%）。
- 本文カラムの背景（中央値）と文字色 `#453735` のコントラストは **8.7:1**。
  情景なしの紙 `#fffcf8` では 11.0:1。霞を薄くして情景を出したぶん、
  前の 9.4:1 から下がるが 4.5:1 は大きく上回る。
- **未確認:** 実アプリ（Tauri / `asset:` 経由のテクスチャ読込）、Intel GPU、Retina での実描画、
  CodeMirror / IME / VoiceOver、`backdrop-filter` の実機負荷、狭幅・200% 文字。
  隔離 WKWebView の採取を実機受入とは扱わない。
