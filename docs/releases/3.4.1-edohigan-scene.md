# 3.4.1 — 江戸彼岸の情景（three.js 二層）

Status: リリース候補。タグ・pkg は未作成
Scope: 江戸彼岸テーマの描画刷新（presentation 層のみ）
Authority: Operational
Last reviewed: 2026-10-22

江戸彼岸を「和紙の上の花」から「夜明けの情景の中に置かれた紙」へ移した。
Markdown source・保存形式・書き出し内容・実行/path/AI 境界は変えていない。
対象は `src/styles/edohigan-theme.css` と ambient / overlay の presentation 層。

## 変更範囲

- **二層構成。** 奥（`EdohiganSceneBackdrop`）が夜明けの空・太陽・光芒・樹冠の影・
  中景/遠景の花弁を描き、手前（`EdohiganThreeAmbient`）が枝のシルエット・近景の花弁・
  紙に落ちる接地影を `multiply` で重ねる。花弁は深度で 1 回だけ分担し、二重に描かない。
- **紙はすりガラス。** 書く面は `rgba(255,250,246,0.56)` + `backdrop-filter: blur(14px)`。
  読む面（`--surface-paper-solid`）は不透明のまま。情景は窓全体（サイドバー・ツールバー・
  ステータスバー）にも回り込む。
- **three.js 0.186.1 を追加。** 動的 import なので main バンドルには入らない。
  テーマを江戸彼岸にしたときだけ別チャンク（736.58 kB / gzip 186.86 kB）を読む。
  main の増分は約 10 kB（+0.6%）。CSS 追加は約 1.6 kB。
- **既定で有効。** 無効化は `?edohigan3d=0` または `VITE_HAZAKURA_EDOHIGAN_SCENE=0`。
  WebGL2 が無い環境では各コンポーネントが CSS 版へ戻り、紙は不透明のまま（v3.4.0 の見た目）。
- 強度（off/subtle/normal/dramatic）、実測フレーム時間による品質段、`prefers-reduced-motion`、
  非表示・非フォーカス時の停止は既存の ambient 予算系をそのまま使う。
  reduced-motion では静止画 1 枚だけを描く。
- 中央の本文カラムは、手前の花弁と接地影がシェーダー側で退避する（既存の可読性契約）。

## 検証

- frontend: **336 files / 3,133 tests**、typecheck、`npm run build:vite`（bundle boundary 込み）。
- 隔離 WKWebView（1280×800、DPR1、非永続）で 2 canvas・強度 4 段を採取:
  normal 75.0 / dramatic 74.6 / subtle 74.6 / off 74.5 fps（p95 16〜17 ms）。
  off で canvas 0 枚。1.2 秒離した 2 枚で 7.13% の画素が変化（静止画ではないことの確認）。
- 本文カラムのコントラストは実測 **6.67:1**（紙 90 パーセンタイル / 文字 2 パーセンタイル、
  3 状態で同一）。紙の平均輝度低下は 1.3%（0〜255）。
- **未確認:** 実アプリ（Tauri / `asset:` 経由のテクスチャ読込）、Intel GPU、Retina での実描画、
  CodeMirror / IME / VoiceOver、`backdrop-filter` の実機負荷、狭幅・200% 文字。
  隔離 WKWebView の採取を実機受入とは扱わない。
