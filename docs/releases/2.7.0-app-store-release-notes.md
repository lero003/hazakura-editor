# Hazakura Editor 2.7.0 App Store Notes

Status: Local App Store/TestFlight candidate; not uploaded or published
Scope: User-facing App Store / TestFlight copy for package `2.7.0`
Authority: Medium
Last reviewed: 2026-08-29

This is a maintenance candidate for the published `2.6.2` line. It tightens
the existing on-device Local Assist helper boundary; it does **not** expose an
MLX model picker or a new provider to App Store users. Local package
provenance is kept in ignored `docs/internal/app-store-candidates/latest.json`.

## App Store Connect Copy

### Japanese

Hazakura Editor 2.7では、Mac上で動くLocal Assistの準備と安定性を整えました。文章の生成中に原稿を書き換えず、差分を確認してから明示的に反映する使い方は変わりません。外部のクラウドAIには送りません。

・会話、提案、差分確認、本文への反映を、これまでと同じ明示的な手順で扱います。
・Local Assistの内部モデルはこのMac上のヘルパーで扱い、取り消しや終了時にはその処理も終了します。
・Markdown sourceを正本とし、auto-save、auto-apply、background indexing、tool callingは行いません。

### English

Hazakura Editor 2.7 tightens the existing on-device Local Assist helper
boundary. Generation still leaves the manuscript unchanged until you review a
Diff and explicitly apply it. Text is not sent to a cloud AI.

- Conversation, Proposal, Diff review, and Apply keep the same explicit flow.
- The Local Assist model stays inside the helper process and is discarded when
  that process is cancelled or closed.
- Markdown remains the source of truth. There is no auto-save, auto-apply,
  background indexing, or tool calling.

## Boundary and non-goals

- This package does not add MLX runtime, model import/download/storage, or a
  model/provider selection UI.
- App Store users do not receive a general model marketplace or arbitrary URL,
  path, remote-code, shell, or Python execution path.
- Safe Editor remains primary; Agent Workbench and external AI/API providers
  remain outside the App Store lane.
- This file is candidate copy only. Upload, TestFlight processing, approval,
  and publication are not claimed.
