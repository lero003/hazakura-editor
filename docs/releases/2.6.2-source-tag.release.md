# Hazakura Editor 2.6.2 Source / Local App Candidate

Status: Local source and App Store package candidate; tag and publication pending
Scope: Right-pane exclusive owner — 参照中の「確認」で差分が出る
Authority: Medium
Last reviewed: 2026-08-27

`2.6.2` is the next local candidate after `2.6.1`. It is not a source tag,
TestFlight upload, App Review, GitHub Release, or publication claim. Physical
Assist validation remains a separate gate.

## What changed since 2.6.1

- Right column is one surface: Reference XOR Preview / e-book / Outline / Diff.
- 「確認」(buffer-vs-disk review), file compare, and the in-pane Reference
  「差分」 action now hide a visible Reference session (retained, not
  discarded) so Diff can show. Closing Diff and pressing 参照 restores the
  same load without a picker.
- While Reference owns the column, the side pane is not treated as visible.
  Switching Preview / 電子書籍 / アウトライン / 差分 from Reference opens
  that pane instead of leaving an empty column or hiding the editor via
  Diff-workbench CSS.

Local Assist conversation / Diff apply, save, and mutation boundaries are
unchanged from `2.6.1` / `2.6.0`. Theme and Preview polish from `2.6.1`
remain.

## Store delta since published `2.4.0`

The App Store What's New draft for this package is
`docs/releases/2.6.2-app-store-release-notes.md`. It restates the unpublished
v2.5 workspace-control line, the v2.6 Local Assist conversation / Diff apply
line, the 2.6.1 Preview / theme polish, and this pane-ownership fix. It is
copy for App Store Connect, not a publication record.

## Release boundary

This is a local candidate. A generated App Store `.pkg` is a TestFlight-shaped
artifact only. It is not an upload or review claim. Hazakura Local Assist
remains an on-device preview companion with no network fallback, auto-save,
tool calling, or autonomous apply.

Build locally with:

```bash
npm ci
npm run build
```

The generated app is a local validation artifact. It is ad-hoc signed and not
Developer ID signed or notarized.

## Known limits

- Detached-window Assist physical smoke (narrow layout, keyboard/focus,
  VoiceOver, streaming/cancel) is still pending. The live helper on this host
  answered `availability: { kind: "available" }` in the `2.6.1` pass; that is
  not the UI gate.
- Source tag, App Store Connect upload, App Review, and GitHub Release need a
  separate explicit approval.
- Published Mac App Store remains `2.4.0` (hotfix only).
- Full built-app smoke-checklist (IME, dirty close, save conflict) is not
  claimed for `2.6.2`; latest-HEAD evidence is the local gates plus focused
  pane tests. Physical 確認-with-Reference remains a smoke-checklist item 20
  check.
