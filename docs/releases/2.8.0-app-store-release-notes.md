## このバージョンの変更

Local Assistを別ウィンドウで使いやすくしました。

- 会話欄を広げ、依頼の入力欄を下部にまとめました。
- 使い方や対象の詳細は、必要なときだけ開いて確認できます。
- 生成の進み具合や完了・失敗を、会話の中で確認できます。
- 文字の大きさとコントラストを調整しました。
- 生成の停止処理と、追加の依頼に失敗した場合の提案の扱いを改善しました。

提案は本文側の差分で確認し、採用したいときだけ文書へ反映できます。
Local Assistの利用にはApple Intelligenceが利用可能な対応Macが必要です。
