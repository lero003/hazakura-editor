## このバージョンの変更

Local Assistの別ウィンドウと、プレビューの読みやすさ・操作性を改善しました。

- 会話欄を広げ、依頼の入力欄を下部にまとめました。
- 使い方や対象の詳細は、必要なときだけ開いて確認できます。
- 生成の進み具合や完了・失敗を、会話の中で確認できます。
- 文字の大きさとコントラストを調整しました。
- 生成の停止処理と、追加の依頼に失敗した場合の提案の扱いを改善しました。

提案は本文側の差分で確認し、採用したいときだけ文書へ反映できます。
Local Assistの利用にはApple Intelligenceが利用可能な対応Macが必要です。

プレビューと表示切替も使いやすくしました。

- 本文を空にしたときや文書を切り替えたときに、前の表示が残る問題を修正しました。
- 表示を更新できなかった場合に、本文を変更せず再試行できるようにしました。
- 文章を選択したあと、プレビューの更新へ戻る処理を改善しました。
- プレビュー・電子書籍・アウトラインを隣接させ、表示切替ボタンの配置を整理しました。
- 既存テーマに合わせて余白や行間を整え、ボタンを押しやすくしました。
