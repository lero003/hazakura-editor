### レビューで見つかった不具合の修正

- 検索の一致位置が**絵文字の後ろでずれる**問題（コードポイント単位へ統一）。
- **4096バイトより後ろの一致が返らない**問題（backendが一致を含む snippet と
  `column` / `snippet_start` / `match_length` / `line_length` を返す契約へ）。
- 画像fitが**25%未満のとき「縮小」で拡大**する問題、縦長画像で**全体が収まらない**問題。
- 読書進捗が**未計測でも値を主張**していた問題と、**文書を切り替えても前の計測**を使っていた問題。
- 生成案の上限を**「入力対象が4,000文字超」と誤案内**していた問題（入力対象／生成案／継続上限を分離）。
- レビュー面が本文を覆ったまま**見えない本文へ入力が届く**問題（面と入力先を一致させ、覆う間は背後の編集面を `inert`）。
- 狭幅でプレビュー／参照を表示中に**レビュー面が隠れてフォーカスできない**問題（開示→再検証→フォーカス）。
- 低い窓で旧フローティング用の**高さ制限が残る**問題。
- 形式を往復すると**入力と「本全体」が失われる**問題。
