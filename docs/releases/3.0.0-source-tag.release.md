## 変更

### モック起点の再点検と実装

- **江戸彼岸（画面20）をモックの明色へ**（紙 `#fffcf8` / 地 `#fbf4f2` / インク `#453735` / アクセント `#975b68`）。
  えるモードは「机 `#fbf4f2` の上に紙 `#fffcf8`」。9月12日に全面の葉影/暗い起動演出を撤去し、枝花と少数の花びらへ置換。
  えるモードで分割バーが窓の約38%を覆っていた既存不具合も修正。
- **スライスC**（06/07/21/22）: 反映後の状態、凡例、停止文言、失敗理由の短い案内。
  生の内部エラー文字列は表示しない。
- **スライスD**（14/24）: 保存衝突の**2版カード**（ディスク側は本文を読まずバイト数と更新時刻のみ）、
  画像プレビューの**倍率**（100% = 画像1px = CSS1px、fitは別物）。
- **スライスE**（09/10/11/04/16/17）: 検索の一致強調と件数、構造のヒント、書き出しの主操作、
  見開きの紙面と下部のページ操作帯、設定の境界説明、文字サイズの確認面。
- **07 本文面化**: 提案のレビューを右下フローティングから**主編集領域**へ。
- **11 形式ナビ**: 書き出しの3コマンドは残しつつ、**共通のダイアログ枠**で形式を選べるように。

### レビューで見つかった不具合の修正

- 検索の一致位置が**絵文字の後ろでずれる**問題（コードポイント単位へ統一）。
- **4096バイトより後ろの一致が返らない**問題（backendが一致を含む snippet と
  `column` / `snippet_start` / `match_length` / `line_length` を返す契約へ）。
- 画像fitが**25%未満のとき「縮小」で拡大**する問題、縦長画像で**全体が収まらない**問題。
- 読書進捗が**未計測でも値を主張**していた問題と、**文書を切り替えても前の計測**を使っていた問題。
- 生成案の上限を**「入力対象が4,000文字超」と誤案内**していた問題（入力対象／生成案／継続上限を分離）。
- レビュー面が本文を覆ったまま**見えない本文へ入力が届く**問題（面と入力先を一致させ、覆う間は背後の編集面を `inert`）。
- 狭幅でプレビュー／参照を表示中に**レビュー面が隠れてフォーカスできない**問題（開示→再検証→フォーカス）。
- 低い窓で旧フローティング用の**高さ制限が残る**問題。
- 形式を往復すると**入力と「本全体」が失われる**問題。
