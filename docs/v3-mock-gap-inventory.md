## 何を測ったか

モック側は `01-shared-system.md`（C02/C04/C05の基準値）、`reference/design-spec.md`、`reference/design-tokens.css`。
現行側は実アプリをブラウザーで起動（`hazakura-note-theme=light` / `hazakura-note-menu-language=ja`、1440×850、等倍）し、
DOMの実寸と計算済みトークンを読んだ。画面01は実画面と `reference/screens/01-welcome.png` を並べた。

**先に結論**：数値系の骨格（上部バー・ステータス・ボタン・角丸・UI文字）は既にモックと一致している。
全画面で差として効いているのは **①面の配色（紙面の暖かさ／ナビ面の色）②開始画面の構造 ③設定の外枠寸法** の3つ。

## 2. 配色（全画面に効く差）

現行ライトテーマと `design-tokens.css` の対応表。数値は実測（現行）と定義（モック）。

| 役割 | モック | 現行 | 差 |
|---|---|---|---|
| アプリ背景 | `#f7f8f5` | `#fafbfa`（`--bg`） | わずかに冷たい |
| 本文の紙面 | `#fffefb` | **無し**（`--surface` `#ffffff` を兼用） | 暖かい紙面の概念がない |
| 操作部／ナビ背景 | `#eef2ec` | **無し**（サイドバーは `--surface-muted` `#f1f3f2`） | ニュートラル灰で、緑みの面がない |
| 汎用surface | `#ffffff` | `#ffffff` | 一致 |
| 控えめな背景 | `#f2f4ef` | `--surface-muted` `#f1f3f2` | ほぼ一致 |
| 本文 | `#24362d` | `--text` `#1a1f1d` | 現行のほうが暗く、緑みが少ない |
| 補助文字 | `#606f64` | `--text-muted` `#6b7670` | 近い |
| 主要操作 | `#356b50` | `--accent` `#2e6b4f` | 近いが、モックは比較案と明記 |
| 淡い選択 | `#e1ecdf` | `--accent-soft` `#eef3f0` | モックのほうが緑が濃い |
| 境界線 | `#dce2d9` | `--border` `#e4e7e5` | 現行は中立灰 |
| 強い境界線 | `#b9c6b8` | `--border-strong` `#c8cfc9` | 現行は中立灰 |
| 追加／削除の背景 | `#e8f1e6` / `#f8e9e7` | 既存Diffトークン | 未突合せ |

`--surface-paper` / ナビ面の意味トークンは現行に存在しない（C04が「必要なら追加」と明示している新設候補名）。
**「面の分け方」が無いことが、全画面の印象差の主因**という見立て。

## 3. 文字（既定値は設定であり、変更は別決定）

| 対象 | モック目安 | 現行の既定 | 扱い |
|---|---|---|---|
| 通常ソース | 15px / 行高1.95 | `editorFontSize` 14 | C05: 既存設定を尊重。既定変更は別決定として記録 |
| プレビュー | 明朝17px / 行高2.1 | `previewFontSize` 15 | 同上 |
| えるモード | 21px / 行高2.15 / 最大幅724px | `lModeFontSize` 15 | 同上 |
| UI | 13–14px | 13px | 一致 |

つまり読み面の「大きさ」は**利用者設定の既定値問題**で、見た目の刷新とは分けて判断する（現行の判断を踏襲）。
