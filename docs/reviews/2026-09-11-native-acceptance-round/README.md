## 優先順（原典の推奨順）

### 1. 書き出しの取消と失敗復帰（F1/F2 の実機確認）
- 本のスコープ（章のあるワークスペース）で **EPUB を開く → PDF へ切替**。切替の準備中に
  **表示中の画面でキャンセル / Escape** → 準備が終わっても**どのダイアログも開かない**こと。
- 同じく準備中に**表示中の形式の「書き出す」を押す** → **仕様どおり実行**される（押せるのに無反応、ではない）。
- 準備が失敗する状況（章が読めない等）→ **残った画面で確定が続けられる**こと。
- 正常系: 切替の間、**枠が消えない・高さが変わらない**（ブラウザfixtureでは 396フレームで0）。
- 連続で切替（PDF→EPUB→HTML）→ 開くダイアログは**常に1つ**。

### 2. Quick Open のキーボード（F3 / R5）
- **⌘P → 文字を打つ → Tab で結果へ移動 → Enter**（実行される）**/ Escape**（閉じる）。
  input・先頭結果・末尾結果のどこでも Escape が**1回だけ**効くこと。
- Tab / Shift+Tab が**枠の中で循環**し、枠外へ抜けないこと。
- 右クリックでは実行されない・閉じないこと。

### 3. 日本語IME（実IMEでの確認）
- 変換中に Enter / Escape / 左右キー / Space が、リスト移動・ファイルを開く・モーダルを閉じる・
  ページ送りに**誤解釈されない**こと（`isImeComposing` の実挙動）。
- 読書面のページ送りと IME の併用。

### 4. VoiceOver
- 読書面: モーダル（書き出し・設定・バックアップ）操作中に**背後のページが送られない**（R1）。
- パレット / Quick Open: 結果にフォーカスして**読み上げと実行ができる**（R5/F3）。
- 書き出しの形式ナビ（タブ）が**選択状態を読み上げ**、Tab/Enter で操作できる。

### 5. 演出（WebGL）
- 江戸彼岸のプレビュー: 上部の影が本文の可読性を壊していない（`multiply` + `opacity:.25` の合成結果）。
- お遊びテーマの強度（DPR cap を一段戻した影響）: 文字入力・スクロール・リサイズ・非アクティブ・
  最小化復帰・Reduce Motion で退行が無いこと。**描画ピクセル上限は normal 約1.78倍 / subtle 約1.44倍**。
- タブ演出（CRTの色収差・深海のグローをタブから引いた状態）が過剰でないこと。

### 6. 信号機とウィンドウ
- 信号機が**バーの縦中央・左の内側余白**に来ていること（{x:21,y:27}）。
- 上部バーのドラッグ領域のダブルクリックで最大化。
- 最小ウィンドウ（960×640）で書き出しダイアログの**フッターが枠内**（R2）。
