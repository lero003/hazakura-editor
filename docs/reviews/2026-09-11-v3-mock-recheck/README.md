## 2. 今回の調査で確定した事実（すべて実証済み）

### F1. モックが定義するテーマは3つだけ。**江戸彼岸は「明色」**（重大）

`reference/mock-styles.css` のテーマ定義は `:root`（ライト）・`.dark`・`.edohigan` の3つのみ（yakou/shokou/shinkai/crt の定義は**存在しない**）。

モック `.edohigan` = `--bg:#fbf4f2 / --paper:#fffcf8 / --ink:#453735 / --accent:#975b68`（**明るい桜色**）

実画素でも確認（支配色ヒストグラム）:
- `20-edohigan.png` → `#fffcf8` 47.9%、`#fbf4f2` 3.2% → **明色**
- `19-dark.png` → `#1d2a23` 28.4%、`#18241e` 4.5% → モック `.dark` と一致

一方、実アプリの edohigan は `--bg:#2a2030 / --surface-paper:#342230 / --text:#f2e4e8`（**暗色の薄暮**、`src/styles/edohigan-theme.css:17-33`）。えるモードではさらに暗色へ上書き（`src/styles/lMode.css:113-119`）。

→ **画面20（江戸彼岸・えるモード）は現在モックと真逆。** また旧棚卸しの「モックに等価定義がない5テーマ」という記述は **edohigan について誤り**（D の「3つだけ」が正しい）。

| 11 書き出し | 1モーダルに左220pxの形式ナビ＋書籍イメージ | EPUB/PDF/HTML が**別コマンドに分離**、形式切替なし |
| 12 Import | 専用2ペイン（原本左・下書き右）＋専用ボタン | ネイティブ確認ダイアログ→未保存タブ→右参照ペイン |

### F3. 画面14（保存の衝突）に**版カードが無い**

`SaveConflictDialog.tsx` は全63行で、タイトル・説明・保持文・3ボタンのみ。「このウィンドウの編集」「ディスク上のファイル」の2版カードは未実装（`grep 'このウィンドウ|ディスク上'` が説明文1行のみ）。モックの画像の核。

### F4. 画面17（設定・Local Assist）の「しないことが分かる」面が無い

`.assist-capability` カードも `privacy-grid`（4つの境界説明）も grep 0件。可用性は `role="status"` の2行が「アプリケーション」カテゴリに埋まっているだけ。**モックの主目的（何を送らないかの明示）が未成立**。

### F5. 画面09（検索）の一致強調が無い

`GlobalSearch.tsx:294-299` は素テキスト描画。`match.column` は React の key にしか使われていない。ファイル単位の件数バッジも無く、summary は「走査ファイル数」でモックの「3ファイルに一致」とは意味が違う。

### F6. 画面24（画像）の倍率操作が無い

`ImagePreviewPane` に zoom/倍率/全体表示は grep 0件（テストも「0 buttons」）。fit は `img { max-width/height:100% }` の暗黙のみ。

### F7. 画面01（はじめの画面）に補足カード・補助リンク・注記が無い

`StartPanel.tsx` に「一冊の本として、読み返す。」カード、`使い方`/`見た目を選ぶ` リンク、`ファイルは、自分のMacに。` 注記が grep 0件。

### F8. 画面20で**演出がダイアログより手前に出る**（具体的な不具合）

`.edohigan-overlay` が `z-index: var(--z-crt-top)`=1200 で、モーダル（`--z-dropdown`=100）とパレット（1100）より上（`edohigan-theme.css:152` / `tokens.css:177,181` / `dialogs.css:11`）。モックは「装飾が本文・ダイアログの前へ出ない」を要求（`pages/20-edohigan.md:28`）。

さらに花びらが全画面の uv 格子に均等配置で、モックの「左右の余白だけ」になっていない（`EdohiganShaderOverlay.tsx:167,178-221`）。

### F9. 既存機能の台帳（C07・保全対象）

コマンドパレット **57コマンド**（file 17 / edit 9 / insert 11 / view 8 / help 6 / review 2 / agent 3 / settings 1）＋ native メニュー。**これらを消さずにモックへ寄せる**のが制約。
