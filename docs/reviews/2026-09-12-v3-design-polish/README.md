## 観察と修正

既存の実App fixture（`../2026-09-11-v3-shell-look/fixture.html`）で開始画面・編集・設定・
書き出しを撮影し、同じ画面サイズの調整前後を比較した。ネイティブ呼び出しはスタブ。
ライト1440×850と960×640、ダーク960×640を確認した。

1. **書き出しの下地と面の区切り**
   半透明の下地に背後の暗い色が混ざり、本文まで灰色に見えていた。既存の
   `surface-paper` に揃え、ヘッダー・形式ナビ・フッターは `surface-muted` で区切った。
   選択中の形式タブは本文と同じ紙色につなぐ。新しい色・テーマは追加していない。
2. **重複する縦余白と、狭幅の左端**
   本文のgrid gapに旧ダイアログの段落・fieldset・確認欄の下marginが重なっていたため、
   本文直下はgapで間隔を管理するよう整理。フッターの説明とボタン間は12pxにした。
   左右の余白を1変数にまとめ、通常24px・低い窓20pxに追随させた。
   960×640でタブ帯8px + タブ内12px = 本文20pxを実測。
   外枠をflexにして、低い窓でformが枠線分だけはみ出す点も修正した。
3. **設定の文字見本の整列**
   ラベルの長さで見本文の左端がずれていた。4行で列幅を共有するgridに変更。
   960px幅では見本文の左端が全行483.52pxに揃い、エディタ22px・プレビュー24pxの
   上限値でも折り返して表示され、本文の横方向のはみ出しはなかった。
4. **設定タイトルがスクロールで隠れるケース**
   カテゴリ移動・入力欄への移動後に外枠のscrollTopが58pxになり、タイトルと閉じる
   ボタンが隠れるケースを再現。外枠を `overflow: clip` にし、本文のスクロールは保持。
   修正後の同じ操作で外枠scrollTop=0、タイトル領域の上端25pxを確認した。
   既存のCSS契約テストに条件を追加し、失敗→成功を確認した。実操作の証拠はブラウザ測定。

開始画面の大きな余白、上部のモード切替、編集本文とプレビューの余白は維持。
