# 実機フィードバック第3弾（7件）の確認と調整 — 2026-09-12

実機で触っていて出た7件。エクスポートの形式切り替え、Local Assist の言葉、読むの紙の余白、
江戸彼岸のプレビューの影、お遊びテーマの強さ、システムボタンの位置、タブの演出。

計測は前回同様、**実アプリ（`App`）をブラウザに描いてネイティブ境界だけスタブ**する
`../2026-09-11-v3-shell-look/fixture.html` を使った（UIは作り直していない）。
**操作は CDP の実マウスクリック**で行う（このアプリのトグルは `onPointerDown` 系なので、
`element.click()` では反応しない）。

## 指摘 → 原因（実測） → 直し

| # | 指摘 | 実測した原因 | 直し |
|---|------|--------------|------|
| ① | エクスポートのEPUBで左側に余白が欲しい | 形式ナビだけ `padding-left: 0` で、枠の左端に接していた（ヘッダー・本文は 24px） | ナビをヘッダー・本文と同じ内側へ。タブ化に伴い、**ラベルの左端**を 24px に揃えた |
| ② | 3ボタンの切り替え感が強い（タブにして下部だけ差し替えたい） | 切替は「今のダイアログを閉じて次を開く」実装で、**本文の高さが違う**（実測 body: EPUB 542 / PDF 434 / HTML 273 → 枠 777 / 669 / 508）＋ 登場フェード（`modalShow` 0.18s）が毎回再生 | 枠を**タブ**にし、本文の `min-height` を最も高い面（542px）に固定して切り替えで枠が動かないように。この面の登場フェードは止める（3形式とも実測 **720×779**） |
| ③ | Local Assist の「言葉を、整える」等は UI 上意味がない／説明は畳んで／作業上の情報を少なく | ヘッダー先頭に `h1`（詩的な題）＋ `p`（但し書き）を常時表示していた | 題を削除。但し書き（安全のための情報）は**畳んであるヘルプ**へ移動。作業に要る情報（対象文書）だけを上に残す。使わなくなった copy `title` も削除 |
| ④ | 読むの見開きで、文字と枠がほぼくっついている | 紙に横の余白だけ指定していた（`padding: 0 39px`）ため、本文1行目が紙の上端に接していた（実測 紙y=195 / 本文y=196 = **1px**） | 上下の余白トークンを新設（`clamp(24px, 3.4vh, 40px)`）。実測 **30px**（左右は40pxのまま、見開きも維持） |
| ⑤a | 江戸彼岸のプレビュー上部に変な影がついて読めない | `.edohigan-canvas` だけ `mix-blend-mode` の指定が無く、**不透明（シェーダは alpha=1）のまま本文より手前**に描かれていた。実測でプレビュー面の紙が **252 → 48** まで落ちた画素があった（他テーマは screen=深海 / multiply=CRT） | `multiply` + `opacity: 0.25`。multiply は**紙と文字を同じ係数で暗くする**のでコントラスト比が保たれ、花びらは淡い影として残る |
| ⑤b | 攻めたテーマなのにつまらない | `Q-THM-1` の最適化で DPR cap を 1.5 に抑えていた（描画が甘くなる） | DPR cap を**一段だけ**戻す（normal 1.5→2 / subtle 1.25→1.5）。フレーム間引きは据え置き（負荷の主因はそちら）。オーバーレイの滲み・ビネットも一段強く |
| ⑥ | システムメニューの位置が微妙 | `trafficLightPosition` は x=9, y=27（y は直したが x が左端に張り付いていた） | モックの内側余白に合わせ **x=21, y=27**（ネイティブ描画なので実機ビルドで要確認） |
| ⑦ | ライト・ダーク以外で、開いているファイルのタブが過剰 | タブの文字にも色収差（CRT）/グロー（深海）を載せていた | タブからは演出を引き、**サイドバーの文字だけ**に残す（契約テストで逆側も固定） |

## 実測値

- エクスポート枠: 切替前 `777 / 669 / 508`（EPUB / PDF / HTML）→ 切替後 **779 / 779 / 779**、ナビ `padding-left: 24px`
- 電子書籍の紙: 本文上端の余白 `1px → 30px`（左右は 40px、`data-spread="two"` のまま 9ページ）
- 江戸彼岸: キャンバス `mix-blend-mode: normal / opacity: 1` → `multiply / 0.25`
- DPR cap: `normal 1.5→2` / `subtle 1.25→1.5`（フレーム間隔は 30fps / 24fps のまま）
- 信号機: `(9, 27) → (21, 27)`
