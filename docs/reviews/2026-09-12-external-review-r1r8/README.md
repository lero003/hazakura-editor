## 誤った保証の取り下げ（原典の指摘・そのまま受け入れる）

原典の「江戸彼岸: 『multiplyならコントラスト比が保たれる』は削除する」は正しい。我々の資料は
誤った一般化を書いていた。

- コントラスト比は `(L明 + 0.05) / (L暗 + 0.05)` で、**同率の暗化でも比は一定ではない**。
  さらに RGB 値と相対輝度は同じ量ではない（sRGB のガンマ）。
- 従って「multiply を入れた」は**指定が入っている証拠**にすぎず、合成後の読みやすさを保証しない。
- 修正: `docs/current-work.md` と第3弾 README の該当記述を**取り下げ**、確認すべき対象
  （本文・薄い補助文字・選択範囲・リンク・ダイアログ上の合成結果）を実機受入に移す。
- 併せて DPR cap の変更も「無コスト」ではないと明記する（実DPR 2以上で normal 1.5→2 は
  描画ピクセルの上限が約1.78倍、subtle 1.25→1.5 は約1.44倍。フレーム間引き据え置き＝負荷不変ではない）。
  確認は演出のFPSではなく**文字入力・スクロール・リサイズ・非アクティブ・最小化復帰・Reduce Motion**。
