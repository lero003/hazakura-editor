## 修正と再現証拠

| 項目 | 変更と試験 |
|---|---|
| Q-01 Save As | 実書込Promiseを遅延し本文・改行・文字コード・別タブ選択を変更。保存済み基準のみ更新しlive sessionの編集を保持。重複保存を抑制 |
| Q-02 復旧 | 起動時snapshotを独立したrecovery keyへ移行。外部変更・削除・移動/bookmark・権限喪失・session無しをlocalStorageと400ms persistenceの結合試験で確認。取り出しは別の未保存タブ。空・巨大な取り出しは元記録を保持 |
| Q-03 閉じる | sessionIdでSave As後のIDを追跡し、完了時dirtyなら閉じない。実React stateのSave/Close統合試験 |
| Q-04 検索 | lowercaseのbyte位置を元の文字列の文字位置に写像。İ・ẞ・K・日本語・絵文字でpanicと列位置を検証 |
| Q-05 文字コード | 保存時encodingと明示再読込を分離。dirtyとI/O中の編集は拒否。EUC-JPかな・漢字・ASCII混在の実byte読込とSave As返却を確認。自動判定の曖昧性は残る |
| Q-06 workspace | 本体成功とbackupWarningを構造化。改名/移動/TrashでUIを実ファイルへ追従。backup衝突・symlink拒否を注入して本体成功と保全を検証 |
| Q-07 export | 画像処理の失敗一覧をPDF/HTMLの最終通知まで合流。前段の実inline失敗を後段へ接続した試験 |

Q-01/Q-02/Q-04/Q-06とEUC-JP Save As、10 MiB、属性保持は修正前の失敗を確認してから修正した。
保存関数を単にtrueにする試験だけに依存せず、保存基準・dirty・復旧領域も確認する。

## 隣接する保全

- 保存するencoded bytesが10 MiBを超えれば、既存/新規ファイルを変更する前に拒否。
- macOS atomic replacementで既存のACL・mode・xattrを開いたfd間でコピー。
  0600権限とFinderタグの実ファイル試験。metadataコピーに失敗した場合は元ファイルを保持してエラー。
- 新規ファイルのwrite/sync途中失敗は、部分ファイルの可能性と別名保存を案内。
  ディスク満杯の実機障害注入は未実施。
- Save As後に単独ファイルbookmarkを保存。取得失敗は主保存成功と分けて案内。
  次回起動のApp Sandbox実機アクセスは未確認。
- 巨大pathless draftを今回のcheckpoint対象から除く場合も、以前の有効な復旧点を保持。
  既存の保存容量・件数・pathless TTLは維持。容量無制限の履歴ではない。

## Local Assistと性能

自作13原稿（fixtureVersion 2）のlive helper評価は15試行中13完成、2エラー。
markdown-linkはunsupported_language、markdown-codeはvalidationで失敗。
helper停止後の新しい生成は完成した。実アプリの取消・別窓操作の代替ではない。
Sandbox制約下のXPC失敗は別実行として除外し、host実行の結果を記録した。

表が文章へ変わる応答を受け、校正のみで数字・URL・コード（inline含む）・引用・表・
見出し/list構造を機械照合し、不一致なら本文へ反映せず再依頼を案内する。
有効な前案の復帰と明示Diff/Apply/Undoを維持する。正当な表内校正も拒否し得る保守的な検査。
固有名詞・意味・省略を網羅検出しない。完成件数は品質合格率ではない。

`node scripts/measure-markdown-render.mjs` は自作fixtureのparse/sanitizeだけを5回測る。
今回のjsdom中央値（100k / 300k文字、ms）: prose 137.5 / 443.6、
表・コード混在651.8 / 4237.4、画像211.0 / 688.5。
WebKitの入力停止・Reader複数章・テーマ・ピークメモリの測定ではない。
300k構造文書の遅さは実機測定の重点。Worker化等の大規模変更は候補へ混ぜていない。

### 2026-09-09 ローカル実機追試

同じ製品ソースのApp Store previewで専用fixtureを使用。署名済みMASアプリは
ローカル起動できなかったため、以下をSandbox/TestFlightの合格には数えない。

- EUC-JPの誤自動判定から明示再読込で正しい日本語へ復帰。
  未保存時の再読込拒否、編集保持、Undo、EUC-JP保存後の実byte照合を確認。
  明示したencodingは次回起動へ固定されず再自動判定されるため、曖昧な原稿は再指定が必要。
- 保存済みfixtureを編集して閉じ、確認画面の保存後にタブが閉じることと実ファイルの編集保持を照合。
  pathlessのSave As/Close競合は自動結合試験で確認し、この実操作と混同しない。
- HTML出力の画像埋め込み、表・引用・コード・最終行を実ファイルで確認。
- 電子書籍は複数ページから最終章へ到達。日本語貼付はIME変換試験とは別。
- Local Assist別窓で校正・短縮を生成し、原文と同じ案は反映不可、短縮案は差分へ表示。
  追加依頼の取消後に前案保持、明示反映でdirty化、ディスク原稿不変、Undoで原文とcleanへ
  復帰を確認。試験中だけ有効化し、利用設定と原稿タブ・workspaceを元へ戻した。

  実機再出力で3ページから2ページとなり、PDFKitの全ページ画像と本文抽出で
  日本語、表、引用、コード、画像、最終行の保持と末尾空白の解消を確認。
