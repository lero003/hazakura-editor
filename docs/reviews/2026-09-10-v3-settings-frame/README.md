## 何をしたか

モック C02 の基準値に合わせて、設定ダイアログの枠と左レールを調整した。

| 項目 | 前 | 後 | 出典 |
| --- | --- | --- | --- |
| 設定ダイアログの最大寸法 | 920×760 | **1100×752** | C02「設定の外枠 1100×752pxの参考」 |
| 左レール幅 | 180px | **200px** | C02「設定の左ナビ 幅200px」／モック15「左200pxのカテゴリ」 |
| レールのパディング | 20px 12px | **23px 14px** | モック `.settings-nav{padding:23px 14px}` |
| レール項目の最小高 | なし（約38px） | **min-height 40px** | モック `.settings-nav .tree-row{min-height:40px}` |
| レールのアイコン | なし | なし（**0個**を実測で固定） | モック15の左ナビは文字のみ |

低いウィンドウでは縮む（`max-height: min(752px, calc(100dvh - 48px))`、幅も `min(1100px, calc(100vw - 48px))`）。
C02 の「200%文字や低いウィンドウでは高さの伸長・内容のスクロールを認める。先に全体を縮小して合わせる実装は不可」に沿う。

## 実測（実描画・等倍）

| ウィンドウ | ダイアログ | レール | 収まり | 横スクロール |
| --- | --- | --- | --- | --- |
| 1440×850 | **1100×752**（基準値どおり） | 200px / column | 収まる | なし |
| 960×640（アプリ最小） | 912×592（縮む） | 200px / column | 収まる | なし |

レールの項目は4つで `svg` 0・`img` 0（アイコンなし）。カテゴリの現在地表示・スクロール連動は前段のまま動く。

## 未決・残り

1. **Help導線**：モック15のレール最下部は「使い方」。現行アプリのHelpはコマンドパレットの `help.*`
   （ローカルデータの説明・サポート診断・プライバシー・OSS表示・アプリについて）にあり、
   **パレットを任意のカテゴリで開くAPIが無い**ためレールからの導線は新規配線が要る。
   モック18の「使い方」画面そのものは新設画面なので、採否は別決定（C07に沿って既存経路は残す）。
2. 画面16（設定・文字と表示）：現行は4つの文字サイズ設定あり。モックの「本文書体」「行間」の永続設定は
   同等の独立項目が無く、モック自身も「別タスク」としている。
3. 画面23（狭いウィンドウ）：1024×748 の実測では**プレビューは自動で隠れ単一ペインになる**が、
   **サイドバーは280pxで開いたまま**（モックは畳む）。一時的な折畳みと利用者設定の分離（モック23の指示6）が要る。
4. 画面24（ローカル画像プレビュー）：既存の `ImagePreviewPane` と `selectedImage` がある。モック24の
   参考寸法（上部59px・情報列54px）との差は未計測。
5. native 受入（VoiceOver / 200% / 実System）は未実施のまま。
