# UI-G3 — 紙面／ナビ面トークンと7テーマの面の分離

Status: Implemented; native acceptance pending
Scope: モックの「紙面」と「ナビ面」を意味トークンとして新設し、全7テーマへ適用
Authority: Evidence
Date: 2026-09-10

## 何をしたか

モック（`20260909_hazakura-ui-implementation`）は `--paper`（本文の紙面）と `--side`（操作部・ナビ）を
汎用 `--surface` から分けている。現行アプリは両方を持たず、サイドバーも本文も同じ面だった。
これは**全画面に効く差**なので、まずここを揃えた（棚卸しは [v3-mock-gap-inventory.md](../../v3-mock-gap-inventory.md)）。

| Commit | 変更 |
| --- | --- |
| （本スライス） | `--surface-paper` / `--nav-surface` を新設し、7テーマで定義。読む・書く面は紙面、サイドバー・chrome・設定レールはナビ面へ |
| （同上） | エディタ面 `--cm-bg` を全テーマで紙面トークンへ統一。設定ダイアログの半透明ガラスを不透明な紙面へ |
| （同上） | 補助文字のコントラスト調整（ライト / shokou / crt）と、テーマ整合テストの単一ソース化 |

`--surface`（汎用の白）は残し、**全 surface を一括着色しない**（C04の指示）。
色の定義元は各テーマファイル、消費者は `var(--surface-paper)` / `var(--nav-surface)` の参照だけにした。

## 7テーマの値

| テーマ | `--surface-paper` | `--nav-surface` | 根拠 |
| --- | --- | --- | --- |
| light | `#fffefb` | `#eef2ec` | モック `:root` の `--paper` / `--side` |
| dark（森の夜） | `#1d2a23` | `#142019` | モック `.dark` の `--paper` / `--side` |
| yakou（夜光） | `#1c1d31` | `#141426` | モック `.theme-mini.yakou` |
| shokou（曙光） | `#f5f8fc` | `#e2ecf5` | モック `.theme-mini.shokou` |
| edohigan（江戸彼岸） | `#342230` | `rgba(46, 29, 44, 0.78)` | 既存の読む面（不透明）を維持。ナビは透過を残す |
| shinkai（深海） | `#14384a` | `rgba(9, 36, 49, 0.78)` | 同上 |
| crt | `#0d1a11` | `#101d13` | 既存の読む面＋モック `.theme-mini.crt` |

`v3-shell` が持っていたライト限定の直値（`--workspace-chrome-surface: #eef2ec` /
`--workspace-chrome-paper: #fffefb`）は、この2トークンへ一本化した。7テーマすべてが同じ面の構成になる。

## 制約の扱い

- **不透明化**：モックの C08「文字を読む面は不透明に」に従い、edohigan / shinkai のエディタ面を
  半透明から不透明な紙面へ変えた。水流・チリの透過はサイドバーとガターに残す（テーマの性格は維持）。
- **汎用surface**：`--surface` `#ffffff` は変えていない。カード・入力・ダイアログ部品の白はそのまま。
- **L Mode**：`[data-l-mode="on"]` は独自の暖色パレットを持ち、`--cm-bg: var(--bg)` を使う。
  今回は触っていない（えるモードの紙は別判断）。
- **文字の大きさ・行間**：モックの 15/17/21px は提案値であり、既存の利用者設定を上書きしない（C05）。

## コントラスト実測（等倍・計算は sRGB 相対輝度）

テーマを切り替えて実測。`--nav-surface` が透過の edohigan / shinkai は不透明換算しない値のため参考。

| --- | --- | --- | --- | --- |
| light | 16.56 | 5.26 | 14.75 | 4.69 |
| dark | 12.56 | 5.10 | 14.14 | 5.74 |
| yakou | 13.61 | 5.51 | 14.93 | 6.04 |
| shokou | 11.69 | 4.87 | 10.41 | 4.66 |
| edohigan | 12.02 | 5.69 | 12.83 | 6.07 |
| shinkai | 10.08 | 4.82 | 13.05 | 6.24 |
| crt | 11.59 | 4.92 | 11.26 | 4.78 |

C08の目標（通常文字4.5:1）を全テーマ・全面で満たす。調整した補助文字：

| テーマ | 変更 | 理由 |
| --- | --- | --- |
| light | `#6b7670` → `#606f64` | ナビ面で4.17だった。モックの補助文字値と一致させる |
| shokou | `#567084` → `#526b7f` | ナビ面で4.34だった |
| crt | `#5a8a64` → `#61916b` | 紙面で4.48だった |

## 意図した差・未決

- **面の差は控えめ**：モックの紙面 `#fffefb` は白に近く、ナビ面も高明度。分離は明度ではなく色温度で作っている。
  もっと強く分けたい場合は、紙面の彩度かナビ面の緑みを上げる調整が要る（今回はモック値に忠実）。
- **開始画面の構造**：モック01は左＝ナビ面のヒーロー＋右＝紙面の一覧。現行は紙面にカードを1枚置く構成で、
  色の役割は合っているが構造は未着手（次のスライス）。
- **レール幅・アイコン・設定外枠の寸法**：`reviews/2026-09-10-v3-ui-g2/README.md` の未決を継続。
- **L Mode の紙と文字既定値**：モックの 15/17/21px と行間を既定へ入れるかは別決定（C05）。

UI-G の横断受入は未完了。UI-G合格・v3完成とはしない。
