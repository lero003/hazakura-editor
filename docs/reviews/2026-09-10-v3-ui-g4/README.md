Status: Implemented; native acceptance pending

Authority: Evidence
Date: 2026-09-10

## 何をしたか

モック01は「左を静かなブランド領域、右を『続きから書く』領域」にする2ペイン構成。
現行は紙面にカードを1枚置く構成で、色の役割は合っていても構造が違っていた。
既存の `StartPanel` のデータ・コールバック・復旧導線はそのまま使い、表示だけを置き換えた。

| 面 | モック基準 | 実装 |
| --- | --- | --- |
| 全体 | 左右1:1・紙面 | `.start-panel` を `1fr 1fr`。実測 720 / 720（1440×850） |
| 左 | ナビ面・上74/左82px・大きな明朝コピー45px/行間1.7 | `--nav-surface`、padding 74 62 50 82、h1 45px 明朝 |
| 左の操作 | 主「フォルダを開く」42px＋副 | `.start-open-folder` を主操作、`新規ファイル`/`ファイルを開く` を副 |
| 右 | 紙面・上68/左右55px・一覧は1列・区切り線 | `--surface-paper`、padding 68 55、1列リスト、下線1px |
| 行 | アイコン／名前／補足パス／日時 | 角丸マーク＋名前(14px)＋パス(11px)＋日時(今日/昨日/9月7日) |

## 追加したもの

- `src/features/workspace/recentOpenedAtLabel.ts`：`openedAt` から「今日／昨日／9月7日」を作る純関数＋単体テスト6件。
  実行時刻に依存しないよう `now` を引数にし、値が不正なら `null`（サンプル日時を固定表示しない）。
- `SafeEditorCopy.startRecentEmpty`（ja/en/kana）：履歴0件でも主要操作を残し、理由を案内する。
- 行の読み上げ名は従来どおり表示名（`aria-label`）。パスと日時は補足として足す。

## 意図した差（モックに寄せない点）

- **補足カード「一冊にまとめて、読み返す」**：既存の導線を持たないため置いていない（画面01は「補足カードは一つに抑える」であり新設の指示ではない）。
- **下部リンク「使い方」「見た目を選ぶ」**：既存メニュー／設定に到達経路があるため、開始画面には複製しない（C07）。
- **サイドバー非表示・タブ非表示**：UI-B2の既存挙動を維持。

## テストの更新（意図的）

`StartPanel.test.tsx` の「行の textContent が表示名と一致」assert を `toContain` へ変更した。
行が名前・パス・日時を表示するようになったため。読み上げ名（`aria-label`）は表示名のままで、
`getByRole(..., { name })` の完全一致assertはそのまま残している。
