# Hazakura Editor Next — ネイティブ技術検証

このディレクトリは、第一世代と独立した macOS アプリの開発用プロジェクトです。現時点では、内蔵サンプルや空の原稿を編集するタブと、選んだUTF-8テキストの原文を読むタブを提供します。配布版ではありません。方針・フェーズは[ロードマップ](../docs/roadmap.md#第二世代設計)を参照してください。

## ビルド・テスト・起動

開発ターゲットは暫定で macOS 26 以降。Swift 6.2 以上と対応する macOS SDK を使います。対応OS・Intel対応・配布方式の最終決定ではありません。npm、Cargo、外部 Swift パッケージは不要です。

リポジトリのルートから:

```bash
swift test --package-path next
bash next/scripts/run-dev.sh --build-only
bash next/scripts/run-dev.sh
bash next/scripts/run-dev.sh --long-sample
```

`--build-only` は `.build/` 配下に開発用 `.app` を作成し、ローカルのアドホック署名と整合性を確認します。配布署名や公証は行いません。通常起動と `--long-sample` はその `.app` を開き、後者は内蔵サンプルを繰り返して生成した長文を表示します。Bundle ID は `dev.hazakura.editor.next.dev`（第一世代とは別）。第一世代の設定・保存場所は読み書きしません。アプリ独自の永続データは現時点では作成せず、将来のデータ領域も第一世代から分離します。保存・復旧は未実装です。終了時に破棄を選ぶと未保存原稿は失われます。内蔵テキストや合成ファイルで検証してください。

## 検証すること・まだ検証しないこと

- **タブと終了:** `⌘T` で空のタブを作成し、タブ名をクリックして切り替えます（最大8件）。編集済みの原稿があれば、タブを閉じるときもウィンドウを閉じるとき（赤ボタン・`⌘W`）も、アプリを終了するとき（`⌘Q`）も、破棄を確認します。変換中は終了せず、確定または取消を待ちます。通常の終了を対象とし、強制終了やクラッシュからの復旧はまだありません。
- **ファイルを読む:** `⌘O` またはフォルダボタンで2 MiB以下のUTF-8テキストを1件選びます。読み取り専用タブに開き、元ファイルに書き込みません。BOMの有無と改行コード（混在を含む）、元のバイト列を保持します。リンクを含む渡されたパス、不正UTF-8、テキストでない制御文字は受け付けません。ファイルを再選択するまで外部更新は表示に反映されません。
- `HazakuraNextCore` は文書 ID ごとに確定原文と編集リビジョンを保持し、開いたファイルのスナップショットを別に扱います。後で使うためのファイルアクセス権や復旧レコードは保存しません。
- `HazakuraNextEditor` はタブごとに AppKit の TextKit 2 を保持し、選択範囲とUndo/Redo履歴を分けます。変換途中の候補は原文に反映せず、確定または取消までタブの追加・切替・破棄を止めます。
- 実機の受け入れでは、開くダイアログと権限、変換の確定・取消、文字列や選択範囲の保持、Undo/Redo、長文の折り返し、VoiceOver、起動と入力応答、メモリを確認します。自動試験とビルドの成功はこの受け入れを代替しません。ファイル編集・保存・競合解決・復旧・UTF-8以外の符号化・サンドボックス・配布・モデル推論は未実装です。
